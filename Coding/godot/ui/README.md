# UI

`design_system/` 保留基础 Theme；`components/`、`overlays/` 当前为空。业务页面放在 `features/<owner>/ui/`，稳定布局使用 `.tscn`。

新增交互时按实际需要接入 Godot 控件，不假定旧触控、拖拽或弹窗组件仍存在。滚动与点击需要区分轻点、拖动和取消；隐藏、暂停、失焦、离树后清理手势与局部计时，并验证下一次操作能够恢复。输入回调中的页面关闭或重建应延迟到安全的帧边界。

页面通过显式依赖接收状态，通过信号表达操作意图。全局浮层由 App 的 Overlay 容器承载；页面不自行创建第二套 App 或查找全局根节点。
