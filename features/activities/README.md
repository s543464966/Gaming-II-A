# 活动页面

本 Feature 拥有活动入口、契约召唤、传说之路、每日任务和七日签到的展示。当前仅接通页面与导航，尚无活动进度、签到计数、召唤、任务刷新或领奖业务，不读取、修改或保存玩家状态。

| 页面 ID | 展示与入口 |
| --- | --- |
| `Activity` | 活动入口，默认展示契约召唤并保留四个常驻页签 |
| `ActivityContractSummon` | 契约召唤；首页「契约召唤」直达 |
| `ActivityLegendRoad` | 传说之路；首页同名入口直达 |
| `ActivityDailyTask` | 每日任务；首页「每日」直达 |
| `ActivitySevenSign` | 七日签到；首页「签到」直达 |

`ui/activity_page.gd` 的 `TITLES` 定义活动页面身份与标题；Home 注册这些身份并按需缓存实例。活动入口默认落在契约召唤，首页快捷入口继续直达对应页签；底部四个页签与左右浏览箭头都经 Home 的既有缓存导航切换，不建立活动内导航栈或全局状态。右上角沿用宿主关闭入口并使用与模式页一致的菱形返回表现，始终返回 Home。

`ui/activity_page.tscn` 提供可编辑的 941×1672 稳定画布：共享深色压纹背景、黑金标题与中央画框、暖纸未开放提示、四格羊皮纸页签和移动黑金选中牌。活动图标归 `ui/art/`，Home 入口引用同一份素材；框面、纸面与字体读取设计系统。各子页继续共享一份场景并用 `page_id` 区分身份，不复制四份空壳。后续有真实活动内容时替换中央 `Stage` 内容，页签和宿主导航保持不变。

当前没有活动业务定义，因此中央画框只显示身份和「尚未开放」状态，不预设奖励格数、任务数、付费档位、抽卡次数、周期或概率。「每日」沿用当前每日任务身份，不额外创建与七日签到重复的签到业务。
