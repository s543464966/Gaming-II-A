# Home 方案素材

Home 共使用 26 个独立 RGBA PNG。原图裁切坐标与素材尺寸见 `home_art_manifest.json`，实际摆位以场景为准，设计画布为 941×1672；其中契约、传说、每日与签到四个入口图标由 `features/activities/ui/art/` 拥有，Home 与活动页引用同一份素材。章节背景保持原图；英雄继续读取当前英雄统一的 `texture_key`，首页不显示英雄名字或铭牌。

头像、姓名牌与资源栏共用 `ui/components/player_header.tscn`，六张原始切图由 `ui/design_system/` 持有，Home 与章节路线读取同一份布局与素材。邮箱与设置仍由 Home 独立装配。左侧使用完整静态底板和五个独立前景图标，右侧三个菱形入口独立。模式选择、开始冒险、英雄头像使用同一张整体设计稿，等比缩放后沿两处竖向金属接缝拆分，三个控件直接相接。连续金边由左侧深色牌面经过纸面延伸至右端英雄嵌框；按钮高 146，英雄入口高 202，保持紧凑与高低错落。

底部商城与五个导航入口只保留独立图标和原生文字，没有共用底板。商城较大并靠左，五个导航入口靠右，间距仍按 `1 : 1 : 1 : 1 : 1.04` 分配。深墨导航图标通过 Home 专用材质映射成浅金主形与深铜内纹，保证石墙上的对比度；透明轮廓与悬停明度仍跟随原生按钮。

素材来自用户提供的首页方案。内置 ImageGen 用于清除文字、恢复纸面与空白竖栏，以及重绘三段一体的操作条；顶栏头像与资源图标直接取自用户原图。生成输出的棋盘格背景及头像空窗底色已清除，轮廓内收一个源像素后统一缩小，避免白边。旧的按钮末端封口与悬浮英雄相框已被这组三段连续素材替换。

## 文字与点击

- 开始按钮固定显示“开始冒险”。章节名称及当前关卡／总关卡由按钮上方的独立标签显示，读取正式章节与现存路线，不为展示创建路线。
- 金币、星石各预留 115 像素文字宽度，六位数保持 29 号字；体力使用独立单行标签，数值全部来自会话，不用万／K 缩写。
- 三段操作条分别命中、提亮，透明斜角与头像框外的台阶留白不响应，相邻段不串色。无底板导航按各自图标和文字的入口范围接收输入，商城与右侧分组之间的留白不触发导航。
- 图标与文案独立提亮，左侧完整底板不参与变色。所有动态文字使用原生字体并在固定范围内适配。
