# 棋盘外观素材

共享卡面已用于战斗与详情：下表中的五档透明卡框位图和数值灰阶表面统一位于 `res://ui/design_system/cards/`；徽章和卡面场景位于 `res://ui/components/content/`。本目录拥有战斗背景、棋盘槽位和外框，并保留锁定图与原始卡框美术来源。

三张棋盘 PNG 按用户提供的四格截图重绘，目标是暗棕凹槽、低对比尖刺旋纹、灰绿卡框和灰白锁头。使用内置 imagegen 图片工具；工具未暴露模型选择，不声称指定了 image-2。原图保留，未修改现有英雄、随从和怪物插画。

| 文件 | 用途 |
| --- | --- |
| `battle_background.png` | 俯视暗石面背景，只在部署、回放和结果状态显示 |
| `board_slot_recess.png` | 当前低对比切角凹槽，由 BattleBoard 逐格绘制，导入尺寸限制为 256 |
| `board_frame.svg` | 当前整盘细金属外框，九宫格拉伸，样式归相邻 battle_theme.tres |

| `battle_countdown.png` | 无字菱形倒计时底图，数值独立 Label，装饰不拦截点击 |
| `board_slot_available.png` | 旧暗红棕槽位原始美术来源，保留原图字节，不再用于运行绘制 |

每格和单格卡牌按 100:118 显示；素材原始像素尺寸不作为布局事实源，统一由 BattleBoard 的 CELL_PROPORTIONS 控制。保留原始 PNG 字节，不将卡名、生命、等级或示例数字烘焙进图片。这些是战斗界面装饰，不是攻击弹道、技能特效或卡牌定义。

顶部统一采用 3px 小圆角矩形：无图标、无环形刻度、无额外独立血条。`card_stats_badge.tscn` 使用独立 ShaderMaterial 绘制薄外框、轻上沿亮边、短下沿阴影和竖直分界，不保留菱形尖角或斜切分隔。左区按数字的实际字宽与留白适配，右侧生命内宽固定为单格宽的 44%，含外沿总宽不超过卡牌宽的 85%；文字与材质共用实时计算的分界，不保留旧的固定比例。左区读取六类主输出与 DesignTokens.output_color 的深色版本，右区为深绿色，仅居中显示当前生命整数，不展示斜杠或生命上限；特殊牌彻底移除左区，将与普通牌等宽的生命条居中显示，不留黑色占位或扩大生命区。文字是原生 Label，保留细黑描边，不写入素材；两区使用紧凑的独立适配字号，字体继续跟随当前语言 Theme，具体字号与几何规范见[卡面表现](../../../../../../Designing/presentation/combat_presentation.md#card-growth-frame)。

灰阶 PNG 保留生成原件字节，导入尺寸限制为 256，避免小徽章携带大尺寸运行纹理。几何、字号、透明裁边和着色在 Godot 完成，不依赖生成图的像素分区；素材本身没有数值、边框或背景占位。准备与战斗复用同一个组件和数据入口；徽章收窄并上移嵌框，多格卡按单格基准控制徽章尺寸、九宫格框边和插画内边距，不把徽章与转角拉长。

## 生成提示记录

### 当前背景与凹槽

两张 PNG 均使用内置 imagegen，以用户确认的暗石面战斗效果图为参考独立生成，保留生成原图字节；不是从包含示例卡牌和文字的整页截图裁切。背景和槽位的压暗只在 Godot 表现层完成，不调暗卡面父节点；整盘外框采用原生 SVG 九宫格。最终提示集：

- 背景：只重建参考图底层背景，9:16 竖幅、严格顶部俯视的古旧暗棕炭灰石地；移除棋盘、全部格子、卡牌、设置、按钮、数字与文字。浅磨损弧形刻纹位于左上及右下边角，仅极少边缘碎石，宽大低对比石缝、柔和左上擦光和轻暗角；中央约 85% 安静连续，低饱和手绘石面。不画矩形外框、网格、凹槽、立面建筑、地平线、宝石或发光符文，输出满幅不透明 PNG。
- 凹槽：只生成一个 100:118 竖幅空卡槽，深暖棕哑光石面／皮革质感、浅凹细切角、微弱上沿内阴影与下沿暖色倒角；中央尖刺旋纹低对比浅压印。画布由槽位铺满，不带外部空白，不画整盘、金亮边、卡牌插画、数字、文字、锁或按钮；手绘材质、细纹理、不透明 PNG，卡牌放到上方时必须更突出。

### 开始按钮与倒计时

内置 imagegen 分别生成两张透明 PNG，参考用户确认的战斗方案与 Home 当前 `enter_button.png` 的纸面、金边；不修改 Home 或模式选择素材。运行时收窄居中，保留 108 设计像素触摸高度，主动作与菱形倒计时分别绑定，数字不烘焙进图片。按钮原图经 AtlasTexture 定位主体后整体适配，固定操作区不参与棋盘高度变化。

最终提示集：按钮为独立横向无字牌面，约 4.3:1，左右对称切角、细层叠香槟金手绘倒角、微暖象牙纸纹、极少角部装饰；匹配确认图的底部操作和 Home 素材，不带菱形、文字、数字、场景或棋盘，轮廓外真正透明。倒计时为独立正方画布上的对称菱形，四个尖角与直边、细层叠香槟金框、暖奶油纸面；匹配参考图底部右侧徽章，不带数字、文字、图标、按钮或背景，菱形外真正透明。

### 原始槽位与卡框提示

三张均独立生成，参考图只提供样式，未作为要求保留像素的编辑原件。共同约束：单张可用的正视平面游戏 UI 纹理，短竖幅 100:118，边框贴齐画布边缘，无外部留白；克制的手绘暗奇幻卡通样式，不加金饰、光晕、额外纹样、文字、数字或人物；输出不透明 PNG。

- 可放置：参考右上空槽，深暗红棕底，约 3% 宽的柔和磨损棕色凹边，内阴影和轻微暗角，中央低对比近黑色尖刺旋纹。不是长条扑克牌。
- 已放置：参考左上卡框，只绘制约 4% 宽的哑光灰绿圆角边框与细暗轮廓；中心纯深棕色，供 Godot 九宫格关闭中心后显示既有人物插画。禁止参考图的角色、5、X2、1 和徽章。
- 锁定：以上述可放置图为底图保持布局、凹边和纹章，中央仅增加约格宽 30%、格高 29% 的闭合锁；粗黑手绘轮廓、灰白多边形锁身、折角锁梁、黑色不规则钥匙孔；背景略暗。

五档边框直接取自用户确认的位图方案，按档位拆成独立透明 PNG，不再由中性母版和着色器染色。运行时把对应 PNG 设为 `NinePatchRect.texture` 并关闭 `draw_center`；九宫格只伸缩无装饰的直边中段，保持角部结构、统一框厚和圆角。插画由共享 `CardFaceView` 统一压入边框下方，并和缺图底色共用圆角裁切。PNG 透明交界的内外沿 2px 使用邻近框色修正 RGB，紧邻的透明像素保留同色 RGB；Alpha 和其余可见纹理保持不变，避免缩放采样产生黑白杂边，也不靠增加描边或继续侵蚀轮廓处理。

正式档位按章内强化 +0／+1／+2／+3／+4及以上映射五色，唯一显示规则见 [Designing 强化边框](../../../../../../Designing/presentation/combat_presentation.md#card-growth-frame)。永久星级、装备等级和敌方难度不参与此映射；外侧状态角线、敌方角标和冲突叉号由独立原生层绘制，不污染人物或等级色。

### 顶部双区表面生成提示

内置 imagegen 生成，不使用 CLI 或外部 API。最终提示：为暗奇幻手绘卡牌顶部轻薄经典斜切徽章制作单张灰阶材质纹理，而非完整徽章或效果图；方形画布完全铺满，无边框、轮廓、文字、数字、图标、投影或外部背景。约 50% 中性灰，以 40%～60% 灰度表达细微哑光干刷和柔和颜料斑驳，不画木板、缝线、明显划痕、裂纹、颗粒点、强光、金属反射或渐变；适于后续染成陶土色与深绿色，低对比且小尺寸仍自然。斜切轮廓、40:60 分隔和实时数值由 Godot 独立绘制，输出不透明方形 PNG。工具没有暴露模型选择，因此不标注指定的模型版本。
