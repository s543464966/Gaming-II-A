# UI 比例与组合检查

视觉依据：[已确认的盒子与布局参考](../Archive/ReferenceImage/donut_sort_layout_and_style_approved.png)。设计宽度为 1024，高度随视口安全区变化；店铺背景、浅色木台、一体式订单底板和纸盒来自 `donut_game_assets_v7`。

## 比例修正

上一版把参考图的可见外框直接当成素材显示尺寸，导致棋盘餐盒拉高、备货餐盒压扁。将首排尺寸改为 174×169 并不能证明贴合参考；此前围绕这些尺寸的结论和测试已撤销。

店铺背景使用 `shop_background_unified.png` 的下部画面，以等比裁切显示黑板、绿植与粉色包装盒；`tabletop_light.png` 等比铺满整个视口并对齐底边，桌面从约 20% 画面高度开始显示，木台前沿落在约 96.5%。较宽屏会从桌面上端裁切纹理，两侧仍由背景铺满。盒位按 5／5／5／2 分为四排并逐排居中，直接排列在木台上，不绘制独立木板。

v7 纸盒的后层与前沿共用 `Rect2(100, 270, 1060, 800)` 裁切区域及相同显示矩形；封口包装使用自身裁切区域。盒位固定为 `200×157` 设计尺寸，每行最多 5 组，棋盘等比缩放上限为 0.84，视口变高时增加行距，不拉高纸盒。甜甜圈堆叠略高于盒口。补盒入场复用相同餐盒场景。订单使用一体式四卡底板，卡位只绘制口味、数量和锁定状态，不单独拉伸每张卡。顶部金币栏与设置按钮距画布左右两侧各 32 设计单位，关卡标题按画布居中；三者共用高 96 的布局区域和同一水平中心线。金币金额在图标右侧左对齐，金币栏和设置按钮通过场景内 AtlasTexture 裁切素材透明留白，使可见图像与布局边界一致。订单进度角标与底板上缘对齐。底部三个道具以同款 `170×170` 设计场景等比放大至 1.1 倍，中心间距为 213，图标与数量角标随场景等比放大。参考图的按钮可见宽度约为画面宽度的 16%～17%，底部留白约为画面高度的 5.5%；当前布局按这一比例保留木台留白。常驻补餐纸盒使用 `235×202` 显示矩形，位于按钮左侧并稍高于按钮中心；棋盘底排与按钮之间保留间距。

甜甜圈在棋盘、订单、拖拽和飞行动画中均等比显示。棋盘的每层甜甜圈按固定层距从盒内向上叠放，纸盒前沿覆盖最下层的一小部分；单颗食物在盒内居中。数字盖使用 v7 封口包装，锁定位置使用同款敞口盒与锁图标，冰霜沿用机关覆盖层。原始 PNG 未修改。

页面在安全区内统一等比缩放，较长竖屏的额外高度由背景和棋盘行距承接。页面模块位置保存在 `donut_sort_screen.tscn`，背景组合归 `donut_background.tscn`，盒位排列归 `donut_board_view.gd`，餐盒组合归 `donut_box.tscn` 与 `donut_box.gd`。

设置与选关面板采用三列四排的十关网格，卡片独立按自身高度在安全区居中。最后一排、第十关和底部操作均完整可见；结算面板继续使用自身尺寸。

## 与参考稿的差异

背景、木台、v7 纸盒、四卡订单底板、金币栏、齿轮按钮与新道具按钮已采用参考稿对应的素材。左上角显示本关真实金币，开局为 0；参考图的 1,280 只是示意。关卡名保留中文，订单进度位于订单底板右侧，补餐区沿用先前确认的常驻纸盒。订单数、口味分布和盒位机关仍由现有关卡决定。

订单数、口味分布、解锁状态和备货数量来自现有关卡。本轮未修改关卡或玩法数据，未重新导出微信包或进行真机验收。
