# 甜甜圈整理消除产品策划方案

更新日期：2026-09-30

本文统一产品定位、核心体验、玩法规则、机制约束与阶段范围，供策划、设计、开发评审使用。后续产品文档细化页面状态、交互表达、逐关配置、接口和交付标准；本方案中决定玩家行为与结算结果的条件、限制和例外继续作为设计依据。

**产品以订单驱动的甜甜圈整理为核心，在有限空间中提供顺序规划的乐趣，并计划通过甜品店装修承接长期成长。当前先打磨百关局内体验，经济与装修属于后续范围。**

## 1 产品定位

### 1.1 产品概述

竖屏休闲益智小游戏，以甜甜圈整理、订单打包和后续甜品店装修为主要内容。玩家在不同盒子之间搬运食物，将杂乱堆叠整理为四颗同味的一盒，再按订单交付。

| 项目 | 产品定位 |
| --- | --- |
| 题材 | 甜甜圈、餐盒与甜品店，延续已选甜品画风，不出现人物 |
| 核心操作 | 点击或拖拽搬运甜甜圈，安排归纳与回收顺序 |
| 单局目标 | 完成全部订单，清空场内与备货中的甜甜圈 |
| 主要挑战 | 有限周转空间、交错层序、订单顺序、隐藏信息和特殊盒 |
| 长期成长 | 闯关积累资源，逐步装修自己的甜品店 |
| 当前重点 | 百关内容、关卡体验与手机适配，当前主要使用场景为抖音小游戏 |

### 1.2 目标用户与产品特色

目标用户假设是喜欢排序、消除与轻度解谜，希望利用碎片时间完成明确挑战的休闲玩家。他们需要快速理解目标，也愿意思考先处理哪种口味、怎样腾出空间。该定位需通过实际试玩确认。

本作把“整理完成”与“订单交付”分开：提前凑齐某种口味可能带来连续回收，也可能暂时占据空间。特殊盒进一步改变材料开放与周转顺序。后续店铺装修把闯关成果转化为可见的外观变化，不引入人物、店员或经营操作。

## 2 核心体验与游戏循环

### 2.1 体验目标

| 体验目标 | 设计支撑 |
| --- | --- |
| 看得懂目标与操作结果 | 订单、顶部口味、空盒及机关状态清楚；搬运、归纳、打包分别反馈 |
| 通过规划解决问题 | 难度来自空间、层序和先后关系；每个机制都有明确作用 |
| 整理成果得到回报 | 同次操作连续回收形成即时反馈，关卡推进形成阶段节奏，后续装修承接长期成长 |

普通关不设置全局步数或时间限制。所有关卡必须存在无需广告、无需道具的通关路径；炸弹关才引入局部倒计时。难度设计优先调整规划负担，不靠遮挡、缩小点击范围或单纯拉长流程制造挑战。

### 2.2 局内与局外循环

局内循环：**观察订单与局面 → 腾位、搬运和归纳 → 推动机关 → 匹配订单并回收 → 更新订单、原位补货 → 继续整理 → 通关。**

订单决定当前交付目标，盒子提供周转空间，特殊机制改变观察与取放条件，有限备货延续处理顺序。归纳与回收是不同阶段，必须在规则和反馈中区分。

局外循环规划：**闯关 → 获得金币与阶段奖励 → 选择装修 → 店铺变化 → 继续闯关。**

基础装修依靠正常闯关收益完成，钻石与连单提供额外选择，不成为区域推进的必要条件。

## 3 基础玩法与共通约束

### 3.1 订单

顶部共四个订单位，初始左侧两个开放且口味已知，右侧两个锁定且口味未知。每个开放位置有独立的后续订单序列，每个订单要求一盒四颗同味甜甜圈。

完成一个订单只推进该位置，其他未完成位置保持不变。锁定位置不参与匹配、不泄露口味；未来解锁后才揭示并参与匹配。右侧的开放方式尚未确定，当前百关全部必需订单由左侧两个位置承接，不依赖右侧解锁通关。

### 3.2 盒位与容器

同屏最多二十五个盒位，包含两个预设锁定周转位；当前 R2 百关实际最多二十个。上限不是每关必须摆满的目标，备货未入场时不占同屏盒位，整关处理的盒数可超过同屏上限。

| 对象 | 定义与边界 |
| --- | --- |
| 普通四格盒 | 容量四颗，装料盒开局可装一至四颗，也可按关卡配置普通空盒 |
| 空盒 | 实体容器仍在，可以按自身规则接收食物 |
| 空盒位 | 原盒已经回收，当前没有容器，不能直接接收食物 |
| 锁定周转位 | 已计入总盒数，解锁后生成空四格盒；不动态增加第三个周转位 |
| 未配置留白 | 不是盒位，不显示可操作容器，也不接受补货 |

每个盒位与每只实体盒分别具有稳定身份：补货替换实体盒，保留原盒位。摆位在关卡制作时预设，开局与重开不随机生成；局内搬运、回收、补货或解锁均不重排。

### 3.3 固定处理顺序

每关为盒位确定唯一顺序，视觉上从上到下，同一排从左到右。不同视觉层次不能上下交叉，同层不能出现与左右位置相反的优先级。设备适配、重开和动画均不重新计算这一顺序。

数字机关选目标、普通冰冻解冻和多个盒子同时可回收时，均按固定顺序处理；同口味订单并存时优先最左侧开放订单。补货跟随本轮实际回收顺序。

所有布局都不增加相邻限制，任意两个符合取放规则的盒子之间均可搬运。布局变化只影响位置表现，不改变容量、匹配或机关规则。

### 3.4 搬运与自动拆分

玩家先选来源盒再选目标盒，或拖拽到目标盒。搬运的是甜甜圈，盒子保持原位。

来源只能取顶部已揭示、连续同口味的一组；普通目标必须有剩余容量，且为空盒或顶部同味。容量足够时整组移入，不足时只搬入能容纳的数量，剩余留在来源。不能任意抽取中间层，也没有手动选择搬运颗数的步骤。

口味不符、容量不足至无法接收、来源或目标受限制时不执行搬运；特殊盒还须符合自身规则。整组搬运计作一次玩家操作。

### 3.5 隐藏层

关卡可以全部明牌，也可以逐颗配置隐藏层。隐藏甜甜圈按规则露到可揭示的顶部时显示口味，揭示后保持已知，不因再次压到下层而恢复未知。

新揭示的甜甜圈即使与本次搬运同味，也不在同一次操作中继续搬走。循环翻顶或补货带来的新内容同样不能延长原搬运。机关限制未解除时，仍遵守对应的取放与信息限制。

隐藏层属于信息限制，不单独统计为特殊盒种类。

### 3.6 归纳与打包

**归纳完成：** 一次有效搬运后，此前未归纳的实体四格盒首次达到四颗同味。归纳不要求当前存在匹配订单，并可推动数字机关。每个实体盒的触发限制见第四章。

**打包回收：** 必须同时满足四颗同味、盒子允许打包、当前开放订单匹配该口味，才整盒离场并完成对应订单。

四同味但订单不匹配的盒子原位等待，不释放盒位、不补货、不计回收。等待本身不额外限制取放，单向等盒型原有的限制仍然有效。不能把归纳、搬空或解除机关当成已经完成订单。

### 3.7 自动连续回收与连单

一盒实际回收后，推进对应订单，再检查其他已凑齐且允许打包的盒子，自动处理到没有新匹配。每只回收盒分别完成一个订单、分别计数。

例如，某订单位依次要求草莓、蓝莓、香橙，后两盒已经整理好。草莓交付后可连续回收蓝莓与香橙，另一个订单位保持不变；同次共回收三盒。

连单采用已确认的同次操作口径：一次玩家操作引发的全部真实回收计为一批，包括订单更新、机关解除和补货带来的自动回收，跨玩家操作不累计。仅归纳、搬空、解锁不计回收；启用奖励时按最高匹配档结算，不叠加各档。未来货币试算与当前连单计数的关系见第七章。

### 3.8 开局与有限补货

首批盒子及后续备货按目标所在半区，从左或右进入固定盒位。底部不展示备货预览，但本关有限、预设的备货队列保留。

开局不额外预留专用补货空位。先处理本轮在场连续回收，再按实际回收顺序，将队首整盒补入可补位位置；每补一盒消耗一盒备货。补入后若产生新的匹配，继续结算到稳定。

| 情况 | 补货结果 |
| --- | --- |
| 可补位盒真正回收，仍有备货 | 队首整盒补入刚腾出的原盒位 |
| 仅把食物搬空 | 空盒保留，不补货 |
| 四同味等待订单 | 原盒保留，不补货 |
| 队列耗尽或本关无备货 | 回收后保持空盒位，不再生成新盒 |
| 已解锁周转盒被回收 | 与普通四格盒一样按队列补货 |
| 单颗暂存盒 | 不打包、不补货，保留用于暂存 |

新补入的是新实体盒，不追溯入场前发生的归纳、减数或解冻事件；其他盒位不移动。

### 3.9 通关与失败

完成本关全部订单，清空场内与备货中的所有甜甜圈，并且没有未解除炸弹时通关，允许保留空盒。全部订单包含尚未显示的后续订单，不能仅按当前场面或顶部当前两单判断。

暂时没有合法搬运不自动判负，玩家仍可考虑道具、周转盒或重开。未解除炸弹到时则本次尝试失败。可解要求针对关卡初始局面，不代表任意误操作后都能挽回。

## 4 特殊机制盒与联动规则

### 4.1 类型与开局约束

九类特殊盒分别保留。当前百关使用八类，数字冰冻单颗暂存盒属于后续规划。以下装量只约束开局实体盒，不误套到局内剩余颗数，也不据此推定备货装量。

| 特殊盒 | 容量 | 开局装量 | 关键规则与设计作用 |
| --- | ---: | --- | --- |
| 数字盖盒 | 4 | 3 或 4 颗 | 内部口味不可见；未开盖不能取放、置顶或打包。被新归纳事件选中才减一，归零开盖，形成材料开放与信息揭示目标 |
| 普通冰冻盒（无数字） | 4 | 3 或 4 颗 | 透明冰层内口味可见；冻结时不能取放、置顶或打包。每次真实回收按顺序解冻一盒，强化订单交付与材料释放的联系 |
| 数字冰冻盒 | 4 | 3 或 4 颗 | 透明冰层内口味可见；冻结时不能取放、置顶或打包。被新归纳选中才减一，归零破冰，提供可提前规划的材料目标 |
| 单颗暂存盒 | 1 | 0 或 1 颗 | 有料时须先取出才可再次放入，不能叠第二颗或交换替换；不归纳、不打包、不补货，食物最终须移回四格盒回收 |
| 数字冰冻单颗暂存盒（后续） | 1 | 0 或 1 颗 | 归零前不能放入或取出预放食物；被新归纳选中才减一，破冰后按单颗盒使用，仍不能归纳、打包或补货 |
| 炸弹盒 | 4 | 3 或 4 颗 | 按普通规则取放；时限内首次四同味归纳即解除，不要求匹配订单。搬空不解除，到时未解除则失败，形成局部处理优先级 |
| 单向收纳盒（只进不出） | 4 | 0 或 1 颗 | 只能按同味与容量规则放入，任何食物都不能取出或置顶，包括预放的一颗；空盒第一颗确定接收口味，满四同味后等待或回收 |
| 固定口味盒（固定颜色盒） | 4 | 仅为空盒 | 预先指定一种口味，空时也拒绝其他口味；允许按基础规则取出，清空后口味限制保留，不具有只进不出限制 |
| 底部置顶盒（循环盒） | 4 | 3 或 4 颗 | 每次成功搬出后，剩余最底下一颗移到顶部，其余保持相对顺序，改变后续可用口味 |

数字盖、普通冰冻、数字冰冻和炸弹开局以四颗为主要设计方向，也允许三颗，不预设统一占比。三颗加盖或冻结盒在解锁前即使剩一格，也不能当作可用容量。

特殊盒应有明确的本关用途。暂存或固定口味可能增加空间，不能仅凭特殊盒数量判断难度。锁定周转盒归辅助功能，不计入特殊盒种类。

### 4.2 每个实体盒只产生一次新归纳

每只实体盒在本关最多触发一次归纳完成。搬走食物再凑回四颗同味，不重复触发归纳，也不重复推进数字。

以下情况均不补计新归纳：

- 开局或补货时已经装满四颗同味：视为已归纳，之后拆开再凑齐也不补领。
- 仅因开盖或破冰露出四同味，或已归纳盒因订单更新而自动回收。
- 单颗暂存盒装满，或数字机关本身归零。

补货产生的新实体盒可以在后续首次由玩家归纳时另计一次。不同实体盒即使口味相同，也可各产生一次新归纳。

### 4.3 数字机关如何减数

每次新归纳，从**当前在场、数字大于零**的数字盖、数字冰冻及未来数字冰冻单颗盒中，按固定盒位顺序选第一只，只让这一只减一。其他数字保持不变。

选中目标归零立即开盖或破冰，同一次事件不再扣第二只；已归零目标不再参与选择，没有正数目标就不减数。新入场目标不追溯先前事件。

数字表示目标还需被选中几次。例如，按顺序的三个目标为 2、3、1，且期间无新目标入场，需要共六次新归纳依次解锁，不能在三次归纳后同时全部解锁。

界面提前轻量标出下一只数字目标，目标归零、入场或离场后更新，让规则顺序可观察。


### 4.4 归纳与真实回收的联动

| 事件 | 新归纳 | 真实回收 | 机关结果 |
| --- | --- | --- | --- |
| 首次四同味，但暂无匹配订单 | 一次 | 无 | 选一只数字目标减一；普通冰冻不解冻；若为炸弹则解除自身 |
| 首次四同味并匹配订单 | 一次 | 一次 | 先处理新归纳与数字，再回收并解冻一只普通冰冻盒 |
| 已归纳的等待盒自动匹配新订单 | 无 | 每盒一次 | 不减数字；每次回收解冻一只普通冰冻盒 |
| 同一实体盒拆开再凑齐 | 无 | 仅匹配并实际回收才计 | 不重复减数字，实际回收仍可解冻 |
| 开盖、破冰或单颗盒装满 | 无 | 动作本身不计 | 不因动作本身继续派生归纳或解冻 |

一次有效搬运先改变食物位置；来源为循环盒时先轮转，再揭示新顶层；随后判定目标新归纳、处理数字及炸弹解除，再处理真实回收与普通冰冻解冻。当前在场连续回收结束后再补货，补入导致的新回收继续结算。

普通冰冻只由真实打包回收触发，一次回收只解冻当前在场顺序最前的一盒，不因“已凑齐”提前解冻。所有机关效果只作用于事件发生时已在场的实体盒。

### 4.5 循环盒的触发边界

一次成功搬出无论一颗还是一组，只轮转一次。仅放入、选中或搬运失败不触发；搬空时不轮转，剩一颗时排列不变。

新置顶的隐藏食物按规则揭示，但不在原操作中继续自动搬走。例如，上到下为草莓、巧克力、香橙、蓝莓，搬出草莓后剩余顺序成为蓝莓、巧克力、香橙。

这是盒子自身的被动机制，与玩家主动选择下层的“置顶”道具分开。

### 4.6 炸弹解除与计时

炸弹首次归纳为四颗同味后，移除标识与倒计时。没有匹配订单时仍留原位等待，作为普通盒使用，不再爆炸；单纯搬空始终不能解除。

炸弹出现且允许操作后计时。入场、教学弹窗、激励广告、设置暂停、切后台及系统自动结算期间暂停；普通搬运动画和非阻断停滞提示期间继续，不刷新时间。重开恢复初始时限，撤回不返还已过去的时间；撤回解除操作会恢复原炸弹状态。

截止前已被系统接受并达到解除条件的操作优先结算，不因后续动画耗时判负。秒数是逐关调校值，须结合真人观察与操作时间验证。

## 5 关卡与难度设计

### 5.1 难度来源与周转空间

每关先确定主要体验目标，再组合口味、装量、层序、订单、隐藏与机关。初始盒数可以在相邻关或同一十关段内起伏，不以更多盒子或更多特殊盒直接代表更难。

| 空间类别 | 计算与设计边界 |
| --- | --- |
| 自由周转空间 | 已可用的普通空盒及空的单颗盒；分散单格与完整四格盒分别考虑 |
| 同味接收余量 | 非空盒的剩余容量，需要满足顶部同味，不能等同任意接收 |
| 受限接收空间 | 固定口味、单向等盒子，须结合指定口味及取出限制判断 |
| 暂不可用空间 | 锁定、加盖或冻结容量；解除前不计为可用周转 |
| 无容器位置 | 空盒位与未配置留白，均不提供接收容量 |

已装一颗的单颗盒不再有余量，冻结单颗盒不提供当前周转，单向盒不能当作自由空盒。

提高难度优先调整装量分布、交错层序和顺接机会，让玩家先腾位、再安排归纳口味；不主要靠增加食物总量、备货或停留时间，也不把所有关卡变成多机制堆叠。口味数、同味相邻比例及 AABB 等只是观察指标，不能单独代表难度。

普通完整空盒不设统一数量。可将满盒中的食物重新分配到原空盒，组合三颗盒、半满盒、装一颗的普通四格盒及完整空盒；例如两只满盒各移出一颗放入原空盒，形成三颗／三颗／两颗。也允许没有完整空盒的开局，但必须存在满足顶部同味的合法周转及无辅助完整解。分散余量不能按同容量直接视作完整空盒，数量守恒之外仍须验证实际层序与难度节奏；第五至十关的落实见 R2 接入记录。

### 5.2 开局与中段都要有规划

首次归纳前的倒换目标须由完整层序验证，不能靠隐藏信息虚增表面难度。关卡中段也应有先整理其他盒、再完成新归纳的需求，避免开局之后一路顺接。

中段目标结合无广告、无道具的完整路线与试玩观察，不代表所有路径的最少操作下限。绕远搬运、空盒互换、拆装已归纳盒和自动连收不能充当新规划；发现更直接的顺接路线时应调整层序或需求，而不是只提高难度评分。具体检查口径见[玩法与关卡验收](gameplay_acceptance.md)。

每个特殊盒应有明确作用，例如先归纳开盖、先交付解冻、投入单向盒前确定口味。需要同时检查锁住的材料、可操作材料与前置事件，避免机关互相等待。

### 5.3 机制教学与复用

引入顺序为：基础搬运与打包 → 隐藏层 → 有限备货 → 数字盖 → 普通冰冻 → 单颗暂存 → 数字冰冻 → 固定口味 → 单向收纳 → 循环盒 → 炸弹。

新机制首次及紧接一关先练习该机制，第三关起可搭配已学机制。综合关通常组合两种，挑战关可用三种，分别作用于不同实体盒。回落关保留熟悉机制，通过放宽空间、层序或目标顺序降低压力；已学机制在后续持续复用。

数字冰冻单颗盒后续只能在玩家已理解冰冻与单颗暂存后引入。尚未教学的机制不能提前出现在副机制或备货中；教学关必须实际包含对应内容，隐藏教学必须有下层隐藏食物。

### 5.4 百关节奏与备货

前三十关保持顺畅学习，普通关目标中位完整通关时长不超过六分钟。第 31—100 关按十关段设置阶段高点，首轮为第 39、49、59、69、79、89、99 关，目标中位完整时长不超过八分钟，随后回落。时长是试玩目标，不是普通关倒计时。

当前 R2 为三十关有备货、七十关无备货。容易关及新机制首次关优先不配置备货，备货教学本身除外。这是百关组合目标，不要求每个十关段恰好三关，也不设置统一的单关备货盒上限。

若试玩超时或频繁重开，优先检查周转空间、订单与备货顺序，必要时减少备货、订单总量或步骤负担，再评估口味数与隐藏比例；不能只调低表内目标分钟数。广告和道具使用用于发现卡点，不作为提高难度的依据。

### 5.5 数量与可解性约束

逐关口味、初始盒、备货、订单、装量与辅助档位集中维护在[百关数值表](levels/level_plan_001_100.xlsx)，不以阶段均值替代实际配置。“初始盒”不含备货，“需回收盒”对应全部有效订单。

必须同时满足以下条件：

- 每种口味的初始食物加全部备货，为四的倍数，并等于该口味有效订单盒数乘四。单颗、单向及其他特殊盒预放食物均计入。
- 初始实体盒数不超过本关已开放盒位；未解锁、加盖与冻结空间不计入当前可用容量。
- 单向盒内食物可以按同味规则补满并等待订单回收；单颗盒食物最终有路径移出；固定口味盒能取得指定材料。
- 每个数字目标解锁前，都有足够可达的新归纳，须逐盒检查顺序，不能只比较全关归纳数与数字总和。未来冻结单颗盒的前置归纳不能依赖其尚未开放的空间。
- 三颗炸弹有在时限内补齐并完成首次归纳的路线；已解除后才按订单等待或回收。
- 真实层序、隐藏、订单和备货顺序下存在完整通关路径，不能仅凭数量守恒认定可解。

改动特殊盒、装量、层序或订单顺序后重新求解。旧配置的完成记录不能证明新配置可用，数值表目标也不等于已经生成或完成试玩。

### 5.6 无辅助基线与两只周转盒

两只预设周转位以稳定身份 A、B 区分，不以设备上的左右位置重新命名。每关验证四种初始条件：双锁、只开 A、只开 B、双开。四种路线都禁用撤回、加餐盒和置顶；默认赠送道具也不能混入无辅助成绩。

| 调校档位 | 首轮安排 | 设计要求 |
| --- | --- | --- |
| 一盒辅助 | 除七个阶段高点外的九十三关 | 只开 A 和只开 B 都应有更易理解、执行的可行路线；试玩按两者较差表现判断 |
| 两盒辅助 | 七个阶段高点 | 一盒应有帮助，双开初始局面有完整可行路线，并用试玩比较通关、重开和耗时 |

双锁且无道具可通关始终是底线。辅助验证针对各自初始条件，不意味着重开保留解锁，也不承诺双开自动获胜、救回任意死局或抵消炸弹到时。

## 6 道具广告与玩家引导

### 6.1 三种道具

每关撤回、加餐盒、置顶默认各一次；重开或切关恢复初始次数，继续同一局保留已用状态。这三次赠送不以观看广告为前提，不使用金币或钻石兑换。

| 道具 | 效果 | 重要限制 |
| --- | --- | --- |
| 撤回 | 恢复上一次成功搬运、加餐盒或置顶前的完整局面，包含整组搬运及整串自动回收、隐藏、订单、备货、机关与本关奖励 | 返还被撤销操作消耗的其他道具，但本次撤回次数不返还；开局不是可撤回操作；炸弹已过时间不返还 |
| 加餐盒 | 启用固定顺序中下一只锁定周转位，生成空四格盒 | 不新增盒位、不消耗备货，与直接广告解锁共用两只预设周转位；没有目标时不扣次数 |
| 置顶 | 在可操作盒中选择一颗下层移至顶部，其他层保持相对顺序 | 未知层可盲选，真正露顶才揭示，原顶层保持明牌；单向盒及未解除机关限制的盒不可使用 |

置顶取消、无效索引、选择原顶层或已知同味的无效重排均不扣次数。次数耗尽或不允许操作时给出原因，不能只让按钮无响应。道具效果与被动循环盒、自动补货分别处理。

广告奖励不能通过撤回后重复领取。广告奖励与普通操作的撤回边界须在产品文档中按现行规则清楚表达，不使已确认的本次解锁因重复操作丢失。

### 6.2 周转盒与激励广告

玩家点击指定锁定周转位并主动确认后才进入激励广告。只有完整观看并收到奖励确认，才解锁所选的一只空四格盒，另一只不变。已开放周转盒容量四颗，按普通规则取放不限次，可打包并原位补货。

奖励只对本次尝试有效，播放前说明范围。退出后继续同一局保留局面与解锁；主动重开则两只重新锁定，原奖励不跨尝试保留。

广告加载失败、放弃、未完成或未获得奖励时，盒子保持锁定，道具次数与局面不变。奖励请求未结算时不执行重开，先处理成功或失败结果，再确认是否放弃当前尝试。重复、迟到或跨尝试奖励不能重复发放，也不能改变新局。

当前仅有本地模拟奖励流程，真实平台广告仍待接入。未来若增加广告补充道具次数，需另行确定次数与限制；右侧订单位解锁也不从本广告规则推定。

### 6.3 首次机制教学

教学覆盖基础搬运与打包、隐藏、备货及各类特殊盒，只介绍当前实际出现的机制。开局出现的新机制，在入场结束、开始操作前说明；补货中首次出现的机制，在该盒入场后、恢复操作前说明。

原则上一关引入一项。确需同关多项时，按预设顺序在各自首次生效前说明，不连续堆叠多个弹窗。同一机制后续关卡及重开默认不重复自动教学，设置中可主动重看。

采用本作素材示意的简短居中卡片与背景遮暗，说明“要做什么”和“会发生什么”，可关闭后继续。教学期间阻止底层搬运并暂停炸弹；文案必须区分新归纳推动数字、真实回收解除普通冰冻。

广告解锁在首次点击锁定盒或触发卡点引导时说明，不在每关开局强制展示广告教学。

### 6.4 停滞提示

停滞可能来自没有发现搬法，也可能来自已经玩死的局面。系统不要求先证明没有合法搬运；在结算稳定后，持续一段可操作时间没有有效搬运，或多次无效取放时，可出现一次可关闭的轻量提示。

提示只写“看广告解锁空盒”，指向尚未解锁的周转位，不提供具体解法或其他帮助选项；不泄露隐藏层、锁定订单和备货中未知口味，也不保证额外空盒一定挽回当前局面。

提示不自动播放广告、不改变局面、不阻断正常操作。有效搬运或关闭提示结束本轮引导；再次引导须先发生新的有效搬运。两只周转盒均已开放，或广告当前不可用时，不展示该广告提示。

教学、广告与设置暂停期间不累计停滞时间。非阻断提示不暂停炸弹，进入广告期间则暂停。触发时长与无效操作次数通过试玩确定，不把参考图的出现时机当作正式数值。

## 7 成长经济与装修

### 7.1 资源定位

正式跨关货币与装修属于后续建设，不因策划中有规则就视为已经上线。

| 资源 | 规划来源 | 用途与边界 |
| --- | --- | --- |
| 金币 | 新关首次通关、连单额外奖励 | 基础装修与额外普通款，保障正常闯关能完成基础推进 |
| 钻石 | 新关里程碑、区域完成、高连单档位 | 可选特色外观，不作为基础装修或区域推进的必需资源 |

周转盒与局内道具不从这套货币试算推导收费，右侧订单位解锁方式保持待定。连单奖励是额外收益，不用于补足基础装修预算缺口。

### 7.2 连单与奖励资格

当前连单按第三章的同次操作规则统计，当前百关未启用货币奖励表。历史本关奖励与未来账号货币不是同一范围，不能叠加发放。

未来首通经济方案保留以下资格约束：奖励在通关时按本关最高有效连单档位结算一次；同一关的重玩、撤回或重复结算不能重复领取首通、连单和里程碑奖励；失败不领取通关奖励。正式跨关经济采用的连单统计口径需要与原稿试算明确统一，不由文档整理自动决定。

首通金币、里程碑钻石、连单加成和装修价格的原始试算完整保留在[经济与装修试算](economy_and_renovation.md)，继续标为试配。正式金额与发奖范围需结合真实通关耗时、通关率及装修间隔制定。原稿中的跨操作八秒连单试算与当前采用口径的差异见[策划核对记录](product_plan_review.md#已存在的版本差异)。

### 7.3 装修操作与进度

首页呈现玩家自己的甜品店，初始有可辨认的基础陈设，沿用已选画风。首区设置六个固定位置：地板、墙面、柜台、展示柜、招牌、灯饰。

玩家选择位置，预览款式与价格，购买并应用后看到变化。每处至少两款普通外观；招牌、柜台等少量显眼位置提供钻石特色款，控制首轮美术规模。

- 某位置首次购买普通款，计一次基础装修进度。
- 已拥有款式免费切换，不重复收费或增加进度；其他未拥有普通款可再用金币购买。
- 特色款只改变外观，不增加基础进度，也不影响关卡规则。
- 六处基础装修全部完成后，区域完成并发放一次奖励，后续可开放新区域。
- 首页展示已完成位置数和下一处可装修位置，主要游玩时间仍集中在整理消除。

装修节奏重点观察首次变化是否及时、两次装修间隔、卡关是否造成停滞，以及资源积压或短缺，再共同调整奖励与价格。

## 8 美术界面与适配

### 8.1 口味与辨识

全游戏口味库最多十五种，当前素材及配对订单贴纸已接入；首轮百关单关最多十种，从库中轮换。口味数根据教学、辨识与周转压力安排，不按关号机械递增，也不要求十五种同关出现。

场内与订单使用一致口味表达，主色与大块配料共同帮助识别。只露下层边缘时仍应可辨味，纸托前沿不遮挡食物层次。暖黄色背景上不使用黄色、金黄色或易被看作黄色的糖霜；香橙保持偏红橙色。

新口味或配料变化必须在实际局内尺寸检查，不能仅凭大图验收。素材清单与配料意图见[口味与美术规范](flavor_art_spec.md)。

### 8.2 信息与状态表现

顶部显示关卡与四个订单，关卡标签不显示难度；中部用于整理，底部从左到右是撤回、加餐盒、置顶。备货队列不预览，首批及补货从左右进入，真实打包向顶部离场。

| 对象或状态 | 必须清楚表达的内容 |
| --- | --- |
| 订单 | 开放口味、锁定与完成状态；锁定时不泄露口味 |
| 普通盒与等待盒 | 顶部口味、层数、空盒及等待订单；不能把归纳反馈当回收反馈 |
| 数字盖 | 与普通盒相同外接尺度，盖面统一底色，仅保留数字，内部口味不可见 |
| 普通冰冻 | 透明冰层与内部口味，不显示数字，真实回收触发后表现解冻 |
| 数字冰冻 | 透明冰层、内部口味与剩余数字，数字归零后才破冰 |
| 单颗盒与冻结单颗盒 | 更短、更窄、边缘更低，冻结状态不掩盖其容量区别 |
| 数字目标 | 提前轻量标出下一只目标，减数时只突出被选中的一只，其他数字不变 |
| 炸弹 | 右下角紧凑倒计时，解除后标识与计时消失 |

保留必要状态、错误原因和操作确认，常态界面不堆叠重复教学。动作表现不能重复执行回收或发奖；暂停、隐藏或离开页面后，恢复时显示一致的已提交局面，不残留临时食物或选择状态。

### 8.3 排列与手机适配

每排最多五盒，优先四至五盒，按实际盒数均衡分排；十六至二十盒使用四排。少盒关不强制四排，也不填充虚假盒位。采用连续紧凑的行列或轻微错位，不做中间挖洞、两侧孤立围合或过大分组空隙。

**开局上下可见留白对称，每侧都大于相邻整排之间的最大可见间隙。** 以食物和纸托的可见边界衡量，同时预留满四层、选中抬起与机关下沿空间。

屏幕宽高、系统安全区和宿主胶囊共同决定可用区域，盒体尺寸与排间距一起自适应，保持等比、可辨和可点击。适配不能颠倒固定处理顺序，也不能拉伸、压扁或重叠素材。

局内回收、补货、解锁和食物变化不触发重排或重新居中。旧图的固定 4×4、围合和底部出餐仅保留历史参考，不覆盖当前已确认布局。

| 美术与界面 | 十五种口味及订单贴纸已接入，按连续布局与可见留白规则适配 |
| 可解性 | 已有百关四种周转条件的正式回放；具体证据见实施记录，不等于最短解或真人难度已验证 |
| 待试玩 | 首试通过率、完整时长、中段负担、隐藏信息公平性、炸弹时间及手机操作 |
| 后续功能 | 真实激励广告、正式跨关货币、店铺装修；数字冰冻单颗盒及右侧订单解锁尚未进入当前百关交付 |

### 9.2 验证重点

首先检查玩家是否理解归纳与订单的关系，是否能辨认限制与可用空间；再比较首试通过、重开、卡点和完整时长。普通关没有“剩余步数”目标，不能套用该指标判断难度。

无辅助可行路线、辅助效果、隐藏公平性、界面适配、平台广告和经济节奏分别验证。可行解不证明普通玩家能合理完成，模拟广告不证明平台可用，屏幕模拟不替代真机。

建议先稳定百关核心体验，再完善平台与辅助，随后基于真实闯关节奏细化经济装修。此顺序服务范围讨论，不代替开发排期。
