# 甜甜圈素材与界面

状态：已接入 `donut_game_assets_v1`，2026-09-22。当前视觉依据为 [新 UI 参考图](../Archive/ReferenceImage/donut_sort_reference.png)；旧 v1～v3 截图只作历史对照。

## 收录与归属

素材包的 66 张 PNG 全部保留原始尺寸、Alpha 与文件字节；11 张甜甜圈归 `Coding/godot/game_content/donuts/art/`，其余 55 张归 `Coding/godot/features/donut_sort/ui/art/`，按 scene、trays、ui、icons、special、effects、props 分类。完整路径、尺寸及 SHA-256 见 [素材清单](../Coding/godot/features/donut_sort/ui/art/asset_manifest.json)。包内预览、HTML 和制作过程文件不作为运行素材复制。

当前 44 张已接入场景或动态状态，22 张收录备用。Godot 导入采用质量 0.9 的有损纹理压缩，保留 Alpha 和像素尺寸；仅运行导入结果被压缩，源 PNG 的 SHA-256 不变。

实际使用的 `.tres` 只定义 PNG 的透明留白区域，不重绘或缩小原始美术。餐盒前后层共用同一裁切区域和显示矩形，出餐纸盒前后层也共用区域，避免独立裁边造成错位。PNG 保留可供后续制作的原始画布。

## 布局与动态状态

基础画布为参考图的 1024×1536：居中粉色标题、右上订单计数、四张纵向需求卡、独立木板上的 4×4 透明餐盒、左下出餐纸盒、右下两盒备货，以及蓝色撤回／绿色加餐盒／紫色置顶。按钮名称在按钮内部，次数角标位于右上。主界面标题、订单计数、Next Boxes、Locked 和道具文案按参考稿使用英文圆体；盒沿 Donut 与纸盒文案使用随包斜体。暂停、选关与规则反馈保留中文。

餐盒按四排坐标排列，所有纹理保留原始宽高比；每个盒组只做整体等比缩放，不用不同的宽高倍率制造透视。720×1280 等较长竖屏将完整的 1024×1536 场景等比居中，额外高度由铺满视口的店铺背景承接，棋盘行距与核心区域比例保持固定。暂停收在右上角，奖励仅在获得后显示。布局由 `donut_sort_screen.tscn` 定义，适配归页面脚本。详细核对见 [UI 比例校准](ui_alignment.md)。

棋盘按后壁、下层至顶层甜甜圈、透明前沿、机关与标记绘制；最上层是实际可搬运的口味。备货复用棋盘餐盒的分层矩形与原图比例，整体缩小；食物最多按 2×2 排列，一到两颗时居中，显示真实队首内容。棋盘甜甜圈从盒底向上堆放，搬运和入场动效同时适配目标排的透视缩放。隐藏层显示独立隐藏纹理；数字盖完整遮住食物；白霜保留透明中心；等待需求使用时钟标记。移动、出餐、补位与预览共享同一口味资源映射。

参考图的 16 单、两张锁定需求卡、口味分布和三个道具数量是示意。实际画面继续展示现有三关的真实订单、解锁状态和次数，不改动关卡配置以拼出示意图。
