# 玩法与关卡验收

更新日期：2026-09-30。本文为专项检查资料，保留规则边界的检查口径与执行步骤，供后续产品文档细化使用，不替代正式需求。[产品策划](product_plan.md)同时保留产品方向与完整玩法约束，不能只在验收资料中保存重要规则。检查要求不等于通过记录；现有结果及限制见[R2 百关接入](r2_level_update.md)，本次文档整理没有重新运行游戏验收。

## 数值来源与交付边界

逐关人工输入只有[关卡数值表](levels/level_plan_001_100.xlsx)，运行内容使用[正式关卡目录](../Coding/godot/game_content/donuts/levels/catalog.json)。来源快照、生成层序、求解路径和实际运行文件应可对应，制作流程见[数值维护](levels/README.md)。

每次改变装量、层序、隐藏、机关、需求或备货顺序，重新求解并绑定新配置摘要。旧配置的完成记录、表格缓存“通过”、装量相等或退出码为零，都不能单独证明新关可用。

## 数量与空间

| 检查 | 通过条件 |
| --- | --- |
| 逐味供需 | 对每种口味，初始食物加全部备货等于该口味有效订单数 × 4，无多余或缺失 |
| 预放食物 | 单颗盒、单向盒及所有机关盒中的食物均计入总量；未来数字冰冻单颗盒同样计入 |
| 容量与盒位 | 初始实体盒不超过开放盒位；两只锁定周转位计入设计盒数，不计可用容量；同屏上限 25，当前 R2 最多 20 |
| 开局装量 | 数字盖、普通冰冻、数字冰冻、循环和炸弹为 3／4 颗；固定口味为空；单颗和单向盒为 0／1 颗 |
| 周转分类 | 普通空盒、顶层同味余量、受限接收和机关锁住空间分开，不把单向、已装满单颗或冻结空间计为自由空盒 |
| 备货 | 仅真实回收产生可补位位置，按有限队列原位补入；搬空、等待或未配置留白不补货 |
| 订单 | 每路独立推进，必需订单由左二开放位置完成，不依赖未确定的右侧解锁 |
| 终局 | 全部订单完成，场内和备货食物清空，未解除炸弹为零；允许剩空盒 |

初始化装量限制不约束局内剩余颗数，也不自动套用到备货；备货实体仍须满足其自身类型与容量规则。

## 四种周转条件的完整路线

每关从各自初始局面验证：A、B 均锁定；仅 A 开；仅 B 开；A、B 均开。四种路线都禁用撤回、加餐盒和置顶，免费赠送次数不能混入无道具成绩。

在真实需求顺序、备货次序与隐藏配置下，用正式规则完整回放，每步检查容量、数量守恒、实体身份和机关状态。当前 100 关应保留共 400 条完整路径；这证明存在路径，不证明最短解或任意局面可挽回。

一盒辅助目标比较只开 A 与只开 B，试玩取较差表现；两盒目标除完整解外，还要比较无辅助、一盒、两盒下相近熟悉度玩家的通关率、重开与耗时。继续同一局保留解锁，主动重开重新锁定，不混淆验证初始条件与实际领奖持久性。

## 机关及事件顺序

- 每个实体盒最多一次新归纳。初始或补入的四同味盒、拆开重组、开盖露出满盒、单颗盒装满均不能补领减数。
- 每次新归纳只选择固定顺序中第一只在场正数机关减一，归零不溢出；逐盒验证解锁前仍有足够可达的新归纳，不能只比较数字总和。
- 普通冰冻只由真实回收解冻，每盒回收只解冻一盒。归纳和回收同一步发生时，先减数字，再回收和解冻。
- 新补入实体不追溯先前事件。隐藏层揭示、循环翻顶或新补入食物不延长原搬运。
- 单向盒预放食物不能取出或置顶，必须能同味补满并匹配订单；固定口味清空后限制不消失。
- 循环盒每次成功搬出只转一次；仅放入、失败、选中不转，空盒与剩一颗不改序。
- 三颗炸弹须有及时补齐四同味的路线；首次归纳就解除，未匹配订单也不再计时，搬空不能解除。
- 未来使用数字冰冻单颗盒时，先验证没有该格也能完成前置归纳，破冰后预放食物可移出；当前百关不能被标为已覆盖此机制。
- 首次教学关须实际存在对应体验，隐藏教学要有下层隐藏；未教学机制不能提前混入副机制或备货。

## 难度与计时

首归纳门槛检查不能依靠未知信息虚增难度，搜索时将隐藏视为明牌核对更短路线。AABB、同味相邻对及容量数据只作调校指标，不能代替完整层序验证。

中段检查沿无广告、无道具的完整路线，在回收进度 30%—70% 区间观察：上次新归纳后，没有任何合法一步可完成新归纳，且至少两次搬运后才发生下一次新归纳，记一段。排除拆装已归纳盒及自动连收；不得故意绕路凑数。Python 与正式会话核对计数，仍只证明该条路线，不证明所有路线的最小负担。

当前求解路线明确为可行解而非最短解。真人记录首试通过、完整时长、重开、卡点、广告和道具使用；普通关以中位完整时长不超过六分钟、七个阶段高点不超过八分钟为目标，不给普通关加倒计时。

炸弹按四种路线中最晚解除步骤暂估时间，并保留待试玩标记；不能把每步假定耗时当真人测量。测试覆盖截止前合法解除、归零未解除失败、搬空仍计时、撤回不返时间及恢复后已过期处理。入场、教学、广告、设置、后台与系统自动结算暂停；普通搬运动画和停滞提示继续计时。

## 道具、广告与操作恢复

| 场景 | 必须核对的结果 |
| --- | --- |
| 撤回 | 上一步及整串自动结算一起恢复，当前撤回次数不返还，炸弹时间不倒流；不能撤销后重新领取同一广告奖励 |
| 加餐盒 | 只开下一只既有锁定位，不增加第三盒、不消耗备货；无目标时不扣次数 |
| 置顶 | 下层上移、其他层保序；取消、无效索引及无效重排不扣次数；未知层不在选择时泄露 |
| 广告失败或放弃 | 不解锁、不加道具、不改变局面 |
| 广告成功 | 只作用于本次请求的目标与尝试，重复回调不重复授予，迟到回调不影响新局 |
| 重开与继续 | 继续保留本次奖励，重开回到初始锁定和赠送次数；待结算请求先处理后再确认重开 |
| 停滞提示 | 不自动播广告、不泄露隐藏、不暂停炸弹；关闭后无有效搬运则不重复弹出 |
| 教学与设置 | 阻止底层输入、正确暂停，关闭后恢复；已看教学可主动重看 |
| 中断操作 | 取消、失焦、后台、隐藏、离树时清理临时动画与选择，恢复显示唯一已提交状态，不重复结算 |

真实广告须另做 SDK 回调、宿主切换与设备验证；本地模拟不计作抖音或微信广告验收。

## 布局与美术

逐关按实际盒数检查连续紧凑分排，每排最多五盒，16—20 盒使用四排；少盒关不补空位。固定顺序与视觉上下、左右一致，不出现隐藏优先级。

在开局食物和纸托的可见边界上，检查上下留白对称且每侧大于最大可见排间隙，同时预留四层、选中抬起与机关下沿。短屏、长屏、安全区和胶囊共同参与适配，素材等比且可点击；回收、补货、解锁不重新居中。

运行十五种口味与订单贴纸配对，辨识检查见[美术规范](flavor_art_spec.md)。覆盖小屏、长屏、不同 DPR、平板及宿主安全区；已有视口模拟不能代替手机真机操作。
