## 2. 术语与固定约束

| 术语 | 定义 |
| --- | --- |
| 盒位 | 本关在中部操作区预先配置的固定位置；一次回收后仍保留该位置。 |
| 实体盒 | 具体一只盒子；补货进入同一盒位的是新实体盒。归纳是否首次发生按实体盒判断。 |
| 空盒 | 实体盒还在、盒内没有甜甜圈，按该盒的规则可以接收甜甜圈。 |
| 空盒位 | 实体盒已经回收、此处暂时没有盒子；不能直接接收甜甜圈。 |
| 未配置位置 | 任意布局中未设置盒位的留白，不是空盒或空盒位，不能接受搬运或补货。 |
| 顶部连续同味组 | 来源盒从最上方起连续相同口味、且口味已显示的甜甜圈。 |
| 归纳状态 | 四颗同口味装在同一只四格盒中，是盒子的状态，不等于打包消除。 |
| 归纳完成事件 | 玩家一次有效搬运后，一只此前从未完成归纳的实体盒首次成为四颗同味。每只实体盒在本关最多触发一次。 |
| 打包回收／消除 | 可打包的四颗同味盒匹配当前开放需求，整盒离场；成功回收一只计一次消除。 |
| 备货队列 | 本关预设、有限、尚未出场的实体盒序列；在可补位盒子回收后按队首顺序原位补入。 |

常规盒容量四颗，开局可装一至四颗，也可以为空；特殊盒必须遵守第7节的专用开局装量，不能套用常规盒的0—4颗范围。“初始装3或4颗”不代表口味相同，也不限制游戏过程中正常搬运后的剩余颗数。两只周转盒位每次新尝试开始时锁定，逐个通过激励广告解锁；解锁后是空四格盒，按常规盒取放、打包与补货。盒子留在原盒位，搬运的对象仅是甜甜圈。两只锁定周转盒位计入本关配置盒位总数，解锁不会新增盒位。

## 3. 页面结构与视觉要求

页面自上而下分为顶部信息区、中部操作区、底部出餐区。现有背景的约25%／57%／18%分区可作竖屏设计参考；适配时保证中部始终是最大的可操作区域。所有盒位完整留在中部，按钮避开底部手势区。背景与纸盒、甜甜圈延续已选甜品风格，页面不出现顾客或其他人物。

### 3.1 顶部：关卡与需求池

- 关卡牌只显示关卡序号，不显示“超难”等难度标签。关卡牌与下方需求池卡片保持20设计像素的视觉间距；不同尺寸按设计比例适配，不硬套物理像素。
- 需求池固定四个位置，初始两位开放且口味已知，另两位锁定且口味未知。开放需求以对应甜甜圈图标表示“一盒四颗同味”的目标，不在图标旁重复写“口味×4”。
- 每个开放位置有独立的有限需求序列。完成一盒后只推进本位置；其他位置保持不变。序列耗尽时显示已完成，不参与后续匹配。
- 锁定位置既不泄露口味，也不参与匹配。前100关所有必需需求配置在初始两个开放位置的序列中，锁定位置不能阻碍通关。
- 两个开放位置显示同一口味时，一盒回收只完成其中一个需求，按从左到右顺序选择。

### 3.2 中部：按关卡配置的盒位布局

- 不再固定4×4。每关选择一种预设摆法：**整齐排列**有清晰行列；**错落排列**保留视觉行，但各行数量或横向位置不同；**自由摆放**为每个盒位单独指定位置，可以没有规整行列。三种摆法均可用于前100关，不与关卡难度或盒子数量绑定。
- 同一摆位类型可使用不同构图。整齐布局可采用矩阵或对齐分组，错落布局可调整各行数量与水平偏移，自由布局可呈围合、散点、中央留白、上下分组或左右不对称。构图建议用于描述画面意图，不是第四种规则类型，也不规定固定盒位数；围合内部及其他留白都不自动成为空盒或可补货位置。
- 已配置盒位总数最多25，包含两个锁定周转盒位。没有配置盒位的留白不绘制可操作空盒；盒子较少的关卡不为凑满画面而摆满25格。
- 每个盒位有稳定ID和相对中部操作区的预设位置；布局类型、可选的构图建议与逐盒位置分开记录，渲染以逐盒位置为准。开局与重开使用该关相同摆位，不能临时随机生成；搬运、回收、补货、开盖、解冻或解锁均不得使其他盒位移动、重排。
- 摆法只改变视觉位置，不改变取放、容量、打包或机关规则，也不设相邻搬运限制。任意两只满足取放条件的盒子都可以互相搬运。
- 每关为所有盒位配置**唯一、固定的处理序号**。整齐与错落布局按可见行从上到下、同行从左到右编排；自由布局按画面从上到下的视觉层次编排，认定同一水平排时从左到右。所属视觉层次及处理序号写入关卡数据，须与画面阅读方向一致；适配不同屏幕、重开或播放动画时不重新按像素坐标排序。该序号统一用于多个等待满盒自动回收、无数字冰冻盒解冻及带数字盒减数。
- 不同视觉层次的盒位中心纵坐标范围不得交叉，上层所有盒位中心必须高于下层；同一层次按盒位中心横坐标从小到大赋处理序号。自由布局若难以看出两盒处于同一水平排，就分配到不同层次，不能用与画面位置相反的隐藏序号。适配不同屏幕时可以整体等比缩放和移动布局，但不得倒置已配置层次的上下关系或同层的左右关系。
- 当前在场有两只及以上数字大于零的盒子时，对处理序号最靠前的一只保留轻量“下一目标”提示；归零、入场或离场使目标改变后，提示随稳定结算更新。提示只说明下次归纳事件将作用于哪只带数字盒，不泄露盖盒内的口味，也不替玩家搬运。
- 两个预留周转盒位在锁定时需与可操作空盒、回收后的空盒位清楚区分；解锁时只在原盒位变为空四格盒，其他盒位不移动，不增加第三个位置。
- 不论本关采用多少盒位，所有盒子完整留在中部，甜甜圈与盒子等比缩放、层次清楚，不重叠、不压扁；点击热区不能互相覆盖。以iPhone上常用触控目标至少44×44pt作为适配检查基准，特别检查自由布局和25盒位密度。空盒、空盒位、锁定周转位和未配置留白应容易区分。
- 数字盖盒与常规四格盒的外接宽高保持一致，盖面统一底色，仅保留较小的数字；单颗暂存盒明显更短、更窄。普通冰冻盒与数字冰冻盒以透明盖和冰冻表现，炸弹数字紧凑置于盒子右下角。

### 3.3 底部：出餐台、备货与功能入口

- 出餐台是首批盒子入场与后续自动补货的动画起点。备货按预设队列排列，界面最多同时预览队首两盒；队列超过两盒时其余暂不展示，不能把预览当作可操作盒位。预览不泄露本关设计为隐藏的层口味。
- 备货队列可以为空；无备货关不展示待补货盒或虚假的“下一盒”，打包后原盒位保持空置。首轮100关约30关配置备货、约70关无备货，具体关号和数量以数值总表为准。
- 出餐区不在开局预先画出专用补货空位。只有盒子成功打包回收后，原位置成为空盒位，才可能由队首整盒补入。
- 三个功能入口从左到右为“撤回、加餐盒、置顶”，与出餐台自动补货分开。底部“置顶”入口也与底部置顶盒的被动规则分开。
- 出餐盒、预览甜甜圈和功能按钮在竖屏适配中不得因空间不足而挤压变形。当前桌布、餐垫与木桌面三种视觉方案保留供设计比较；静态图中的三颗甜甜圈或数字角标只是美术示意，不作为正式备货数或道具次数。

### 3.4 口味视觉与素材范围

全游戏口味目录最多15种，首轮100关单关暂按最多10种配置；需求池、盒内、备货预览对同一口味使用一致的主色和醒目配料。前期配置基线使用现有六种：草莓糖针、巧克力坚果、抹茶奶霜、蓝莓果粒、香橙糖针、葡萄糖针；现有“橙色”素材对应香橙糖针，糖霜需呈偏红橙色而非黄色。其余九种香草奶油、红心火龙果、树莓果酱、焦糖海盐、薄荷巧克力、黑芝麻、开心果碎、紫薯奶霜、咖啡摩卡在被排入前100关之前须完成相应素材与辨味检查，不要求每关或整个前100关用满15种。

局内背景偏暖黄，甜甜圈不使用黄色、金黄色或容易被看作黄色的糖霜主色；自然面包胚的小面积暖色不作为黄色口味。每种口味除主色外还应有大面积糖霜纹样或配料特征；下层只露出侧边时也要尽量可辨。同色系口味须在实际局内缩放尺寸下检查辨识度，不依赖微小色差。隐藏层未揭示前不得以颜色、轮廓、备货预览或图标泄露真实口味。

## 4. 核心交互与结算

### 4.1 开局与重开

按本关配置初始化四位需求池、预设布局与盒位、两只周转位、首批实体盒和有限备货队列。首次进入本关及玩家主动重开时，两只周转位锁定；退出后选择继续同一局，恢复离开时的完整局面和该次尝试已解锁的周转位。开局从底部出餐台将首批盒子摆入其指定盒位；未入场备货不占中部盒位。开局已经四颗同味的实体盒标记为已归纳，但入场本身不产生归纳完成事件；若匹配开放需求，仍可正常自动打包。前期教学关宜避免开场即回收，先让玩家产生主动整理体验。

设置入口提供“重开本关”。重开恢复该关原始盒位、实体盒、甜甜圈层序与隐藏状态、需求序列、备货顺序、机关数字与倒计时，不把上一次尝试的搬运、消除或道具表现带入新局；两只周转位也重新锁定，上一次尝试的广告解锁奖励不保留。重开入口须让玩家在确认前知道这一结果。退出后若选择继续同一局则不执行重开，保存并恢复离开时的局面、计时和已解锁状态。重开不是底部三个功能按钮之一。

### 4.2 选中、搬运、成组与拆分

1. 玩家先点可取出的来源盒，再点目标盒。再次点击已选来源盒可取消选择。
2. 只读取来源盒顶部已经显示口味的连续同味组；隐藏层未露出前不可取出或预先选中。
3. 普通目标盒必须有剩余容量，且为空盒，或其顶部与搬入口味相同；特殊盒另须遵守自身限制。无实体盒的空盒位不能接收。
4. 容量足够时整组移入；容量不足但至少能放一颗时，自动移入可容纳的数量，余下留在来源盒。目标只剩一格时从连续同味组移入一颗。
5. 来源、目标相同，口味不符、目标已满、盒子锁定或不可取放时均不执行搬运；盒内层序、需求和队列保持不变，给出可识别反馈并保持来源选中。有效搬运完成后清除选中。

### 4.3 明牌、隐藏层与暂存

同一关可以全明牌，也可以明牌与隐藏层并存。隐藏甜甜圈在上层被搬开、自己露到顶部时才揭示。刚揭示的口味即使与本次搬运相同，也不在这次操作中继续自动搬走。

搬空的是空盒，仍可按盒规则接收甜甜圈；只有整盒成功回收才产生空盒位。四颗同味但暂不满足需求的盒子在原位等待，仍可按其盒型规则取放，不因“等待需求”额外锁定。

### 4.4 首次归纳与打包回收

一次有效搬运后，若一只此前未归纳的实体四格盒首次成为四颗同口味，产生一次归纳完成事件。即使该口味不是当前需求，也计归纳。每只实体盒最多一次：搬走再凑齐不补领；开局或补货时已经四颗同味的盒子标为已归纳，拆开再凑齐也不能补领。开盖、破冰、需求切换、自动回收、单颗暂存盒装满都不凭空产生归纳完成事件。新补入的实体盒有独立归纳记录。

同时满足“四颗同味”“该盒当前允许打包”“至少一个开放需求是此口味”时，整盒自动打包并从顶部离场，完成对应位置的一盒需求，计一次消除。锁定需求不参与匹配；等待需求的满盒不消除、不腾位、不补货。两项事件可以发生在同一步，但必须分开计数和表现。

### 4.5 需求更新、连续回收与补货

一盒成功回收后，推进其匹配需求位置的序列，其他位置不变。若此时场上已有可打包、四颗同味且匹配任一开放需求的盒子，无需玩家再点，按固定盒位顺序选第一只自动回收；每次回收分别推进需求并再次检查，直到当前在场没有可立即回收的盒子。若同一口味同时匹配两个需求位置，选左侧位置；一盒不能完成两个需求。

先处理本轮所有当前在场的自动连续回收，再按回收的先后顺序处理待补盒位，每个可补位位置从备货队首补入一只新实体盒。新盒保持预设内容与隐藏状态，其他盒子不移动；补入后若已有满足需求的可打包满盒，继续自动回收并重复稳定结算。队列耗尽即停止，不生成新盒。搬空、等待需求、单颗暂存盒均不触发补货。解锁后的周转四格盒若成功回收，按常规盒补货。

新补入盒不追溯入场前的归纳和消除机关事件。开局、补货时已满同味只标记为已归纳；是否能打包仍按当前需求检查。

### 4.6 单次操作的确定结算顺序

有效搬运先更新来源和目标内容；若来源是底部置顶盒，随后按第7节完成该盒置顶；再揭示刚露顶的隐藏层。接着判定目标盒是否首次归纳，若本关配置数字机关，按固定盒位顺序只选当前在场、数字大于零的第一只带数字盒减1，归零时立即开盖或破冰。同一次归纳不继续扣第二只盒。之后检查当前可打包盒，逐盒打包、更新对应需求；每次真实回收只使一只在场的无数字普通冰冻盒解冻，并继续检查待回收盒。当前在场连续回收处理完毕后按回收顺序补货，检查新入场盒，直到局面稳定，最后判定通关或炸弹失败；停滞引导按第4.10节独立判断，不作为这一步的“无解”结算。

动画播放期间不重复接收搬运提交。数据结算与动画展示遵守同一顺序，一次有效操作不能复制、丢失甜甜圈或使盒子超过容量。

### 4.7 通关、重开与炸弹失败

本关所有已配置的需求序列均完成，且场内和备货中的甜甜圈全部清空，稳定结算后才通关；空盒和仍锁定的需求、周转位可以保留。当前场内暂时没有甜甜圈，但备货或需求未完，不能误判通关。

玩家可以随时从设置主动重开本关。系统不因玩家停滞或暂时没有合法搬运就自动宣告“无解”；停滞时只按第4.10节提示可看广告解锁空盒，解锁后也不保证当前局面能挽回。若本关配置炸弹且其倒计时到零仍未按规则解除，则直接判定本关失败；炸弹的时钟细则见第7节。

### 4.8 新机制首次教学

教学对象包含首关的基础搬运与四颗同味打包，以及后续首次引入的隐藏层、原位补货和本关实际配置的特殊盒；未出现的机制不提前教学。每项机制以稳定的教学标识记录是否看过，跨关卡、同关重开和退出重进保持；只有玩家关闭教学卡片后才标记已看。设置中可主动重看已经解锁的教学，重看不重置首次弹出记录。

开局已呈现的新机制，在入场动画结束、玩家可以操作前弹出；随补货首次出现的机制，在该盒入场后、玩家继续操作前弹出。首次引入关原则上只教一项新机制，并让其后数关先练习该机制；同关确有多项时按关卡预设顺序，在各自首次生效前分别展示，不连续堆叠弹窗。教学采用局面遮暗、居中卡片、本作甜甜圈与盒子示意，一张卡只说明该机制的关键操作及结果，提供清晰的关闭入口。弹窗期间不接收底层搬运并暂停炸弹倒计时。

数字盖盒、数字冰冻盒和数字冰冻单颗暂存盒的教学须说明“首次归纳出四颗同味，让按盒位顺序选中的一只数字盒减1”；无数字普通冰冻盒须说明“成功打包回收一盒，按顺序解冻一盒”。不能将两种触发条件合并，也不能沿用参考图中的螺丝名称和数值。锁定周转盒的广告条件在玩家首次点击该盒或看到停滞提示后进入解锁流程时说明，不作为每关开场的强制教学。

### 4.9 两只周转盒的激励广告解锁

两个锁定周转盒是本关已配置盒位，不额外新增位置。玩家点击其中一只锁定盒时，显示可取消的“看广告解锁空盒”确认入口，明确本次奖励对应所选盒位，且只在本次尝试有效、主动重开后会重新锁定；玩家确认后请求平台激励广告。只有平台确认完整观看并发放奖励，才将所选盒位解锁为空四格盒，另一只保持原状。解锁后按普通四格盒取放、打包和原位补货。玩家退出并选择继续同一局时恢复已获解锁状态；主动重开本关时两只周转盒都重置为锁定，新尝试若再次需要解锁，须重新由玩家自愿观看广告。

玩家取消、广告加载或播放失败、未收到奖励确认时，所选盒位仍锁定，盒内外局面与道具次数不变；等待广告结果期间不重复发起该盒解锁，也不执行重开，先结算当次广告结果再允许玩家确认是否放弃本次尝试。同一奖励回调不得重复解锁或改变另一只盒。无可用广告时不出现虚假的成功状态。广告播放期间暂停炸弹倒计时并禁止底层搬运；广告结束后恢复。逐关必须仍有不看广告、不用道具的可行通关路径。

### 4.10 停滞时的空盒提示

玩家可能漏看可行搬法，也可能已经把本次尝试玩死；停滞提示不尝试区分这两种情况，不进行“无解”宣告。在局面稳定且可操作期间，持续没有有效搬运或连续多次无效取放时，可以出现不阻断操作、可关闭的轻量提示，文案只写“看广告解锁空盒”，视觉上指向尚未解锁的一个周转盒位。提示不展示具体搬法、隐藏口味或其他帮助选项，不自动播放广告；点击锁定盒后仍须按第4.9节由玩家确认。

有效搬运或关闭提示即结束本轮引导；再次引导须先发生新的有效搬运，避免玩家原地反复被催促。两只周转盒均已解锁或广告当前不可用时不显示该提示。教学、广告和设置暂停期间不累计停滞时间；提示本身不暂停炸弹倒计时。持续时间与无效取放次数作为可调参数由试玩定值，验收时可用测试参数触发，不能把参考截图的出现时机直接当作本游戏阈值。

## 5. 前100关难度原则、机制顺序与逐关验证

本版规定整款游戏的通用难度原则与广告辅助边界；前100关具体的初始装量、备货、口味、特殊盒、难度高点及构图建议由[1—100关关卡数值总表](../levels/level_plan_001_100.xlsx)逐关记录。该表目前完成装量试配及数量检查，尚未制作完整逐味层序、需求与机关序列，不是已生成、已求解或已试玩的可玩局面。

### 5.1 难度来自周转与决策

整体加强玩家“先腾位、再归纳、再安排回收”的规划要求，针对空位过多、同味过易衔接、无需提前思考的问题调整。优先把同样数量的甜甜圈更集中地装入普通装料盒，减少散落在多个盒子中的易用余量；随后调整真实口味层序、隐藏信息与两条开放需求的顺序。减少盒数有时反而提高周转压力，不能将盒数、口味数或机制数单独当作难度。

基础教学与新机制首次出现保留明显可理解的操作；练习关逐渐增加首次归纳前的倒换，综合关再组合多项已学机制。部分综合关可有更多特殊盒，但以各自独立的实体盒实现，不能擅自把多种特殊规则叠在同一盒上。AABB允许出现但受逐关占比目标约束；同时控制相邻同味段和一步即可归纳的机会，避免仅把AABB换成同样易整理的其他排列。

整体采用起伏节奏，前30关保持学习顺畅；第31关起每十关安排一处特别难高点，其后回落，新机制首次引入时再次降低其他压力。普通关目标中位完整通关时长不超过6分钟，特别难高点不超过8分钟；具体关号及逐关目标只在数值表维护。这是试玩调校目标，普通关不出现全局倒计时。提高难度不以增加总甜甜圈、备货或流程长度为主要手段，也不通过拥挤、缩小点击区域或辨味困难制造障碍。

备货不是每关必备。前100关首轮约30关有有限备货、约70关队列为空；相对容易的关卡优先不用备货。该比例控制关卡组合，不是单关备货盒数量上限，也不要求每个十关段都恰有3关。无备货关打包后不补入新盒；有备货关才按第4.5节原位补货。若完整通关时间超目标，调整备货、需回收盒与实际搬运负担，不能只改表格中的时间数字。

### 5.2 机制引入与广告辅助

机制按玩家学习顺序依次引入：基础搬运与打包 → 隐藏层 → 原位补货 → 数字盖盒 → 普通冰冻盒 → 单颗暂存盒 → 数字冰冻盒 → 固定颜色盒 → 单向收纳盒（只进不出） → 底部置顶盒 → 炸弹盒。数字冰冻单颗暂存盒须在两项基础机制都已学会后才可组合；本次数值表仍将它留后续，不加入前100关。新机制首次出现时配首次教学、较宽松的空间和信息条件；接下来的练习关先巩固，再与已学机制组合。具体首次出现关号和数值只在总表维护，本文不复制逐阶段配置。

每关都有两只可选择解锁的周转盒，以稳定盒位ID区分为A、B，不依赖画面左右位置。首轮把七个特别难高点作为“两盒辅助档”，其他关卡作为“一盒辅助档”：后一类应分别验证**只开A**和**只开B**在本次尝试中的可执行通关路径，前一类一盒应有帮助、两只在本次尝试中解锁后应有明显更顺畅的路径。策划试玩目标暂按一盒辅助档两种单盒条件中较低的首次尝试通关率至少90%、两盒辅助档至少95%试配，并记录样本和实际结果；达不到则调关。解锁两盒不自动通关、不保证错误操作后的当前死局可救，也不免除炸弹时限。每关无广告、无道具仍须存在完整通关路径；不能把广告设为通关前置条件。

### 5.3 装量、空间与层序指标

数值文件的“装量配置”按开局／备货、盒型、盒数、容量、每盒颗数和机关数字记录配置组；同一组可以展开为多只实体盒，不能将表格的一行误认成一盒。机关数字不同的盒子分行。主表汇总实际装量，不用“非空盒数×4”推定总甜甜圈，也不把“空四格盒（含受限）”直接当作通用空盒。

初始实体盒指开局在场的普通与特殊盒，备货尚未入场；数据统计中两只广告锁定周转位单列，不计入已可取放盒数。配置盒位总数须包括这两只位置，最多25个。初始非空四格盒、初始空四格盒、单颗盒与广告锁定位分开统计，不能重复计数；需回收盒数等于有效需求总数，不等于初始盒数。

### 5.4 从数值试配到可交付关卡

每关完整配置至少记录关卡编号及配置标识、布局类型与逐盒坐标、稳定盒位ID、视觉层次及固定处理序号、初始实体盒ID与盒型、容量、自底向上的逐颗口味及隐藏标记、初始装量与归纳状态、两只广告周转盒ID和锁定状态、两条开放需求的完整序列、有限备货实体盒及顺序、各特殊盒的数字／指定口味／炸弹时限、首次教学标识与触发时点。构图标签、装量配置组和难度评分都不能代替实际局面。生成时使用随机性则须固定种子或保存生成结果，同一次尝试不临时改写层序、需求或备货。

退出后继续同一局要恢复实际局面、实体盒归纳记录、机关状态、需求进度、备货进度、计时与已解锁状态；主动重开恢复该关初始数据，两只周转盒重新锁定，跨关教学已看记录保留。求解与试玩记录对应具体关卡配置；改变装量、层序、需求、盒位处理顺序或机关参数后，旧验证结果不再作为该关新配置的通过证据。

制作与验收须逐关满足：

1. 按第7节逐盒检查容量与开局装量。每种口味在初始盒及全部备货中的甜甜圈数必须等于该口味有效需求盒数×4，包括单颗暂存、冰冻暂存和单向盒中预放的颗数；不能只检验全关总数。单关最多10种口味。
2. 盒位不超过25且包含两个广告锁定位，初始实体盒各有有效盒位；按四类空间分别统计，备货为零不假画待补盒。空白、已回收盒位和未解锁容量都不能参与搬运。
3. 生成真实逐颗层序后复核装满度、AABB、相邻同味对、一步归纳与首归纳搬运目标。容量装量通过但层序未制作时，只能标为装量通过；不能声明难度已生效。
4. 用实际需求、备货、隐藏揭示、盒型限制和固定顺序，分别求解双盒锁定、只开A、只开B、双盒解锁的初始条件，记录可回放解法与搬运数。未证明最优的路线只能记录为已找到的可行路线，不能填“最短搬运”；未完成搜索也不能直接声称无解。无广告无道具路径必须存在，隐藏信息是否让普通玩家有合理决策依据另由试玩检验。
5. 逐步模拟数字机关目标，验证每只盒在其被解除前都有足够且可达到的新归纳事件；数字总和与总归纳数相符只是粗筛，不能拿锁在盒内的材料反过来证明自身可解锁。普通冰冻必须存在真实回收触发，不能靠只归纳未回收解除。
6. 单向盒已有一颗时，验证能按该味补满并匹配需求回收；固定颜色盒验证能取得其指定口味的足量材料；三颗炸弹盒须能补齐、等待必要需求并在时限内回收。炸弹同时验证暂停与临界结算，不用求解耗时代表玩家操作时间。
7. 以熟悉度可比较的玩家记录首试通关率、完整通关耗时、重开与卡点，区分无广告、只开A、只开B、双盒条件；一盒辅助档取A、B中较差表现。实际解锁时点也须记录，不能把开局辅助条件的通过率承诺成任意死局的救援率。未求解与未实测字段保留待验证，不复制目标值。
8. 首次机制先教学再操作，未配置不弹教学。三种布局均保持处理顺序与阅读方向一致，设备适配不变序；所有盒位留在中部，点击热区互不重叠。

## 7. 已确认特殊盒规则与机制使用边界

以下是已确认盒型的完整规则。前100关按第5节及数值总表逐步接入，某关未配置的盒型不出现、不参与结算。数字冰冻单颗暂存盒作为后续组合机制列明，不属于本期100关必须实现或配置的盒型；不能因文档写有规则就自行提前引入。

### 7.1 容量、开局颗数与取放规则

| 机制 | 容量 | 开局允许颗数 | 取放、解锁与回收规则 |
| --- | ---: | --- | --- |
| 数字盖盒 | 4 | 3或4 | 未开盖不可取放、不可打包，内部口味不可见。数字表示还需被新的归纳完成事件选中几次；选中才减1，归零开盖后按普通四格盒取放与打包，不必等待回收才开盖。盖面仅显示较小数字，与普通四格盒同外接尺寸。 |
| 普通冰冻盒（无数字） | 4 | 3或4 | 透明盖内口味可见，外有一层冰；冻结时不可取放、不可打包。每真实打包回收一盒，按固定盒位顺序只解冻一只在场的无数字普通冰冻盒。归纳但未回收不解冻；破冰后按普通四格盒使用。 |
| 数字冰冻盒 | 4 | 3或4 | 透明冰冻盖内口味可见；冻结时不可取放、不可打包。被新归纳事件选中才减1，归零破冰后按普通四格盒取放和打包，无需先回收。 |
| 单颗暂存盒 | 1 | 0或1 | 空时可接收一颗；已有一颗必须先移出，不能叠第二颗或交换替换。容量小于四，不产生归纳、不打包、不补货；预放或后续放入的甜甜圈最终须移回四格盒参与归纳与回收。 |
| 数字冰冻单颗暂存盒（后续） | 1 | 0或1 | 透明冰冻盖显示数字；归零前不能放入，也不能取出预放的那颗。被新归纳事件选中才减1，归零破冰后成为普通单颗暂存盒，仍容量1、不归纳、不打包、不补货。 |
| 炸弹盒 | 4 | 3或4 | 按基础规则取放，右下角只显示紧凑剩余秒数，如45。必须在时限内匹配需求并成功回收炸弹所在盒才解除；归纳但未回收、把该盒搬空都不解除。到零仍未解除则本关失败。 |
| 单向收纳盒（只进不出） | 4 | 0或1 | 只能放入，盒内任何甜甜圈都不能取出，包括开局预放的一颗。空盒第一颗决定后续接收口味；已有一颗时只接收该味，仍遵守同味成组与容量拆分。四颗同味首次计归纳，需求不匹配时原位等待且仍不能取出，匹配后正常打包回收。 |
| 固定颜色盒 | 4 | 仅0 | 开局为空并预先指定一种口味，只能接收该味；空时也拒绝其他口味。允许按基础规则取出，不具有只进不出限制。首次四颗同味计归纳，按需求等待或打包。 |
| 底部置顶盒 | 4 | 3或4 | 按基础规则取放；每次成功从该盒搬出后，将剩余最底部一颗移到顶部，其余相对顺序不变。放入、选中或搬运失败不触发；搬空无变化，剩一颗排列不变。一颗或一组搬出都只触发一次，新置顶颗不在同次自动搬走，若隐藏则揭示。四颗同味按普通规则归纳、等待与打包。 |

“空订单盒”在本版统一更名为“单向收纳盒（只进不出）”，不是顶部需求池中的订单位置。旧数据若使用旧称，需按只进不出的盒型对应；不能当成任意取放的普通空盒。底部置顶盒是被动特殊盒，与底部“置顶”道具入口不同。

### 7.2 初始状态与配置边界

- 数字盖盒、普通冰冻盒、数字冰冻盒和炸弹盒开局以4颗为主，允许3颗；没有固定全局占比，不把本次数值表的试配占比写成永久规则。底部置顶盒同样只允许3或4颗，其比例按各关配置。
- 上表“开局颗数”仅约束本关开场实体盒。游戏中合法搬运后的0、1、2、3、4颗状态由容量与取放规则决定，不自动恢复开局颗数、不自动填料。也不能将开局限制直接推断为所有备货的永久装量规则；本轮备货按数值表试配为普通四格盒、每盒4颗，实际入场内容须来自明确的备货配置。
- 3颗加盖或冰冻盒虽然物理上剩1格，限制解除前仍不能使用；空的数字冰冻单颗盒也不能在解冻前接收。预放甜甜圈不会增加容量，单颗盒始终容量1。
- 初始各颗口味、层序及隐藏规则必须实际配置；3或4颗并不代表同味。预放在特殊盒中的甜甜圈计入逐味总量与需求配平，不能在加载后临时补一颗或删一颗以适配盒型。
- 数字机关初始数字须为正整数，普通冰冻不带数字；数字显示0是归零后的开放状态，不能仍标为加盖或冰冻。同一实体盒不额外叠加未定义的其他特殊类型；不同盒上的已学机制可在综合关共存。
- 初始已四颗同味的特殊盒标为已归纳但不产生事件，盖住或冰冻时不能打包；开盖或解冻后若需求匹配可自动打包，但不补记归纳。单向或固定颜色盒凑满时同样遵守一次实体一次归纳，不增加额外奖励事件。

### 7.3 两类机关事件与计时

数字盖盒、数字冰冻盒、数字冰冻单颗暂存盒共用同一选中顺序：每出现一次新的归纳完成事件，从事件发生时**当前在场且数字大于零**的所有带数字盒中，按本关固定盒位顺序选第一只，只给这一只减1。数字“2”要求这只盒先后被两次新的归纳事件选中；两次可以来自相同口味的不同实体盒，不要求匹配当前需求或触发打包。归零的盒子不再参与选择，同一次事件不能继续扣下一只，新补入场的盒子不追溯旧事件。例如固定顺序中三只盒分别显示2、3、1且期间无新带数字盒入场，须依次取得2、3、1次归纳，共六次才能全部解锁，绝非三盒同时减数。

同一实体盒拆开再装满不会再次推动数字。开局或补货已经四颗同味的盒子、开盖或破冰露出的满盒也不补记归纳。无数字普通冰冻盒独立由**真实打包回收**触发：一次回收只解冻当前在场的一只，自动连续回收中的每只盒分别计算。归纳与回收同一步发生时先处理数字、再处理回收和普通解冻。

炸弹在出现且可操作时开始计时；教学弹窗、激励广告、入场、设置暂停、切后台及系统结算期间暂停，普通搬运和非阻断式停滞提示不刷新或暂停，重开恢复原始时限。倒计时归零前系统已接受且满足打包条件的操作优先判定成功，不因离场动画耗时而失败。

## 8. 道具、经济与本版接口边界

本版纳入**两只预留周转盒**逐个观看激励广告解锁的完整交互与奖励状态。广告请求、完成、失败和奖励确认应分别处理；只凭平台奖励确认解锁，回调须绑定本关、本次尝试及所选盒位并防止重复发奖。广告待结算时不执行重开；若回调发生在退出当前页面之后，只记录其对应尝试的有效奖励，不误解锁正在游玩的另一关或已重开的新尝试。玩家继续同一局保留解锁，主动重开会重新锁定；广告播放前明确告知本次尝试有效。开发时可使用可控模拟回调验证页面逻辑；本期最终验收仍须使用真实平台广告回调完成联调，不能将模拟广告称为已完成真实接入。

底部三个道具入口与周转盒广告奖励分开。三个道具未来也由玩家自愿观看平台激励广告获得，但现阶段未明确各自的正式效果、每次广告奖励次数与使用限制，故本版只验收其入口布局和未接入状态，不据演示代码填入临时效果。道具广告加载失败、放弃或未获奖时不得增加次数或改动局面。所有100关必须无需广告和道具即可通关。

金币用于局外基础装修，钻石用于可选特色装饰，连单按真实连续回收判断；这些属于全游戏系统。本版不把策划中的每关100金币、8秒连单窗口或装修价格试算写成局内正式结算，不在顶部额外堆放货币余额。

## 9. 验收与交付

设计与开发共同以本版为准。应交付可运行的第1—100关局内页面、逐关完整配置与可解验证结果、首次教学卡片与已看记录、停滞引导、两只周转盒的广告解锁及平台奖励回调联调结果、工程源码和启动方法；凡关卡实际配置的特殊盒，都须交付该机制的状态与交互验收。静态效果图、浏览器小样或需求文档本身不能代替程序、广告平台或真机验收。

| 编号 | 验收场景 | 通过标准 |
| --- | --- | --- |
| AC-01 | 竖屏布局 | 上中下三区完整，中部最大；无人物、无难度标签，内容不越安全区。 |
| AC-02 | 需求池 | 四位初始两开两锁；锁定不泄露、不匹配；两位同味时一次回收只推进左侧匹配位一盒。 |
| AC-03 | 三种摆位与多种构图 | 整齐、错落、自由布局均可由关卡数据呈现；同类可切换不同构图，至少用围合与散点两种自由布局样例验证；盒位数可不同、总量可到25且含两锁定周转位，未配置留白不成可用盒位。 |
| AC-04 | 固定顺序 | 三种布局均按已配置的画面阅读顺序选择自动回收及机关目标；自由布局的处理序号唯一且可预测，设备适配和重开不改变顺序，回收补货不使其他盒位重排。 |
| AC-05 | 搬运与拆分 | 顶部同味组整组移动或按目标剩余容量拆分；目标不超过盒容量；无效操作不改变数据。 |
| AC-06 | 隐藏与辨味 | 隐藏层露顶才揭示；同次不连带搬走；前100关实际使用的口味在需求、场内、预览表达一致，单关不超过10种，糖霜主色无黄色或金黄色，香橙款不会被看作黄色。 |
| AC-07 | 归纳与等待 | 新实体首次四颗同味只计一次归纳；无需求时留场、不打包、不补货；普通盒可再取放，单向盒仍只进不出，其他盒遵守自身限制；同实体重复凑满不再计。 |
| AC-08 | 打包与需求 | 满盒且可打包、匹配开放需求才顶部离场；每盒只完成一个需求并只计一次回收。 |
| AC-09 | 连续回收 | 需求更新后等待满盒自动按盒位顺序回收，未完成的另一需求位置不变。 |
| AC-10 | 原位补货 | 有备货时，场上连续回收处理完毕后按回收先后由队首补入原盒位；仅搬空不补，队列耗尽不生成新盒；预览最多两盒且不可搬运。无备货关从开局即不显示待补货盒，回收后不补货。 |
| AC-11 | 归纳事件边界 | 开局已满、补货已满、解锁露出满盒、同盒重复凑满、单颗暂存装满都不额外生成归纳事件。 |
| AC-12 | 数字机关（仅配置时） | 同场多个数字盒时，下一目标在归纳前有轻量提示；一次新归纳仅使该只减1，其余不变，归零或补货改变目标后更新提示；重复口味的不同实体盒分别可触发。 |
| AC-13 | 普通冰冻（仅配置时） | 无数字冰冻盒只由真实回收解冻，一次回收按固定顺序只解冻一只；等待需求的归纳不解冻。 |
| AC-14 | 单颗与炸弹（仅配置时） | 单颗盒只能装一颗且不打包补货；炸弹只能由所在盒按需求回收解除，暂停与归零判定正确。 |
| AC-15 | 结束与重开 | 全部需求及场内、备货甜甜圈清空才通关；停滞时不自动宣告无解，设置内可主动重开；炸弹超时直接失败。 |
| AC-16 | 第1—100关数据 | 一百关各有明确配置，记录布局类型、构图建议、逐盒位置与唯一处理序号；构图标签不能替代坐标；口味与需求数量逐味吻合、盒位不超25；每关有双盒锁定条件下的完整可行解。未完成的行不得标为已验证。 |
| AC-17 | 难度安排 | 相邻关不强制增加盒数；能从可用空位、层序、信息、需求或备货顺序解释主要难点；普通关中位完整通关时长目标≤6分钟，特别难高点≤8分钟；不以AABB占比或单纯加盒代替调校。 |
| AC-18 | 按钮与平台边界 | 底部三入口顺序正确；未接入的道具显示不可用且不改动局面，不显示虚构次数；道具奖励不与周转盒广告解锁混用。 |
| AC-19 | 动画与状态 | 快速连续点击、自动回收和补货期间无重复结算、甜甜圈丢失或复制，图像保持比例。 |
| AC-20 | 自由布局可用性 | 自由摆放的盒位均留在中部、彼此不遮挡且点击热区不交叉；最小支持屏幕上仍能辨味和准确点击；视觉位置变化不产生相邻限制。 |
| AC-21 | 首次教学 | 首关基础规则以及后续实际首次引入的隐藏层、补货、已实现特殊盒在可操作前展示对应教学；每项只自动展示一次，重开和跨关不重复，设置内可重看；教学遮暗时不能搬运，炸弹计时暂停，数字归纳与普通冰冻回收的文案不混淆。 |
| AC-22 | 停滞引导 | 用可调测试阈值分别触发久未有效搬运和连续无效取放；提示只写“看广告解锁空盒”，不判断有解或无解、不提供搬法或其他帮助，不阻断操作或暂停炸弹；关闭或有效搬运后本轮结束，无可解锁盒或无广告时不误提示。 |
| AC-23 | 周转盒广告解锁 | 两个预留盒位逐个解锁；取消、失败、无奖励均保持锁定，真实奖励确认只解锁本次尝试所选盒且不重复发奖；退出后继续同一局恢复解锁和局面，主动重开两盒重新锁定，广告待结算时不重开，延迟回调不得解锁新尝试；广告前告知奖励范围，广告期间暂停炸弹。模拟回调只验页面逻辑，最终验收须完成平台真实广告联调。 |
| AC-24 | 无广告可通关与辅助档 | 100关逐关验证双盒锁定、道具不使用时存在完整通关路径；一盒辅助档分别验证只开A和只开B，两盒辅助档验证双盒都开。试玩分条件记录通关率与重开；解锁不自动获胜，也不保证救回已玩死的局面。 |
| AC-25 | 备货占比与无备货界面 | 前100关首轮约30关有备货、约70关无备货；无备货关不显示虚假备货预览或补货动画，有备货关队列有限且数量不受统一盒数上限约束，以完整通关时长调校。 |
| AC-26 | 四格特殊盒初始装量 | 数字盖盒、普通冰冻盒、数字冰冻盒、炸弹盒、底部置顶盒分别测试3与4颗合法；0、1、2或超4颗的开局配置不通过。前四类整体以4颗为主，具体配置逐关核对。运行中合法搬出后变为2、1或0颗不报初始装量错误，也不自动补回。 |
| AC-27 | 单颗暂存初始状态 | 普通单颗暂存盒开局0、1颗均正确呈现；已有一颗拒绝再放，移出后可接收，装满不归纳、回收或补货。数字冰冻单颗暂存盒不进入本期100关；后续实现须分别验证0、1颗冻结时均不可取放，归零后保持容量1，且预放颗只能在解冻后移出。 |
| AC-28 | 单向收纳盒 | 开局0或1颗有效，2颗及以上无效；预放和后放颗均不可取出。空时首颗确定口味，异味不可放；按剩余容量接收成组的一部分。凑满无需求等待时仍不能取出，需求匹配时可正常回收。 |
| AC-29 | 固定颜色盒 | 开局仅0颗有效，预放任何颗数均不通过；空时和非空时均只接收指定味；已放甜甜圈可按基础规则取出。盒上标记不会被误解为只进不出。 |
| AC-30 | 锁住的余量 | 三颗盖盒／冰冻盒的剩余1格不参与合法目标计算，解锁后才按当前顶层接收；无数字冰冻不被新归纳误解冻。初始已归纳满盒开盖或破冰后不再减数字，但符合需求可回收。 |
| AC-31 | 底部置顶与三颗炸弹 | 底部置顶盒只在成功搬出后翻一次，组移也一次，失败或放入不翻，新置顶隐藏颗揭示但不跟随本次搬走；三颗炸弹验证补齐、需求开放、回收与时限，搬空不解除。 |
| AC-32 | 逐味守恒与配置展开 | 配置组按盒数展开为不同实体；预放在暂存和单向盒的颗数计入对应口味。对每种口味核对初始及备货总数等于需求数×4；总数正确但某味多或少的配置仍不通过。 |
| AC-33 | 周转指标生效 | 从真实层序计算装满度、AABB与相邻同味对占比、开局一步归纳目标数；按无广告无道具条件验证首归纳最少搬运下限。未达标须调整实际局面；不得仅改评分、算上锁定位或用冗余操作凑搬运数。 |
| AC-34 | 机关前置资源 | 按固定顺序逐步验证各数字盒解锁前可产生所需新归纳，且每实体仅一次；不能用冻结或加盖盒内尚不可用的材料满足自身解锁。普通冰冻的前置必须是真实回收。总量正确但顺序不可达仍不通过。 |
| AC-35 | 难度节奏与机制组合 | 基础及新机制教学保持清晰，练习逐步增加倒换；综合关可有多只已学特殊盒，各盒身份和限制清楚。同一盒不叠未定义特殊规则，不靠增加总量、遮挡或缩小热区完成提难。 |
| AC-36 | 数值状态与实际验证 | 装量检查、逐味层序配置、四条件求解、试玩与平台／真机验收分别记录；只找到可行路线不称最短，缺少实测不填目标冒充。变更局面后重验相关结果，原有易版的通过记录不充当本版证明。 |

本版仅将需求明确到可开发、可核验的程度；尚未交付的100关配置、首次教学、周转盒广告、特殊机制、道具或真机表现均须在实际完成后再按相应验收场景检查。
